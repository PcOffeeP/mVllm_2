# 子视频人工审核工具

本工具读取当前统一生成的候选视频，供用户逐片观看、填写五类标签和保存审核决定。源视频标注与候选标签仅作参考，首次审核时不会自动填入答案。审核记录独立保存，不修改源标注、数据划分、生成清单或视频；确认标签不等于数据发布。

## 输入与输出

| 项目 | 位置与用途 |
| --- | --- |
| 候选和视频 | `data/sub_video/manifest.json` 和 `data/sub_video/videos/`；包含开发集与固定测试集候选。 |
| 来源与划分 | `data/videos/` 的源视频，以及 `data/splits/three-fold/` 的七份成员文件。片段继承原来源的集合和三折归属。 |
| 核验提示 | `data/sub_video/audit.json`；仅在它记录的清单摘要与当前清单一致时展示，供人工重点检查。 |
| 标签规则 | [标签说明](../../docs/label.md)；输入值及组合按当前规则校验。 |
| 人工审核 | `data/subvideo-review/reviews.json`；开始时为空，逐次保留审核修订，并由 Git 跟踪。审核后需提交记录，视频和本地锁文件不进入 Git。 |

## 启动

需要 Python 3.11（`pyproject.toml` 要求 `>=3.11,<3.12`）；服务使用 Python 标准库和 `fcntl`，适用于 macOS、Linux。

```bash
cd /Users/pcoffeep/AgentPlayground/active-projects/TensileAgent-Finetune
python3 -m script.subvideo_review.server --project-root . serve --port 8765
```

打开服务输出的本机地址；默认是 [http://127.0.0.1:8765](http://127.0.0.1:8765)。服务只在本机监听。如果端口已被占用，换一个端口，并使用启动时显示的地址。保持服务运行；关闭终端或停止服务后页面将无法继续保存。

## 审核

1. 按开发集／测试集、三折训练／验证归属、来源、审核状态或重点提示筛选，选择片段。页面展示来源、原视频区间、帧映射、生成时建议关注的内容，以及源标注和候选标签参考。
2. 播放片段，根据片段画面逐项填写断裂状态、断裂模式、断裂位置、三项异常和五项现象。覆盖窗口的候选标签初值已由生成规则写入（含经 coverage 路由的来源），人工审核可以覆盖；没有标注不等于“否”或“无”。人工审核决定本身仍默认留空（按 DEC-003 第 11 条）。
3. 尚未填完时可保存草稿；需要讨论或处理时填写原因并记录疑问或退回。确认需要填写全部 11 项且符合标签组合规则。保存成功后会显示修订编号。
4. 修改已确认的结果时，非草稿决定需要说明原因。先保存当前填写内容，再切换片段；未保存的内容不会自动进入记录。可使用“查看原视频”核对来源画面。

重新打开同一清单与记录库时，工具按片段、媒体、来源、划分和标签规则等身份找回相应修订；身份不同的同名旧修订会隔离，不自动套用。播放及保存前校验媒体摘要；文件缺失、摘要不符、划分不一致或清单在运行中变化时，应先核对，不要把报错当作审核通过。

## 导出与继续

服务运行时，页面底部有两个导出按钮：「导出审核记录」下载最新审核结果，文件名为 `subvideo-reviews.jsonl`；「导出全部修订」下载完整修订历史，文件名为 `subvideo-reviews-history.jsonl`。两个按钮都在服务运行时直接下载。

服务运行时可打开[最新审核结果](http://127.0.0.1:8765/api/export)或[完整修订历史](http://127.0.0.1:8765/api/export?all_revisions=1)下载；若端口不是 8765，请使用实际启动地址。也可在项目目录执行以下命令，输出到自选文件；已有同名文件会被 shell 覆盖：

```bash
python3 -m script.subvideo_review.server --project-root . export > /tmp/subvideo-reviews-latest.jsonl
python3 -m script.subvideo_review.server --project-root . export --all-revisions > /tmp/subvideo-reviews-history.jsonl
```

最新结果包含未审核占位行；完整历史包含各次修订。两种导出都不是正式发布，不要用导出文件覆盖 `reviews.json`。下次使用时保留独立审核记录及其对应的清单和媒体；Git 跟踪记录不代表视频已备份。

**失效条件：** 启动方式、输入输出路径、标签规则、身份校验、保存或导出行为变化时，须同步更新本文并重新核对对应流程。
