# 开发集初步子视频裁剪

本工具承接当前标注、固定划分和 ROI，按旧窗口规则生成初步片段。它只处理开发集，不重新划分，也不生成测试片段。初裁结果供统计和新规则审查，不能直接当作已人工审核或已发布的数据。

## 输入与输出

相对输入均以 `--project-root` 为根：

| 输入 | 路径与要求 |
| --- | --- |
| 当前标注 | `data/annotation-table-full.csv`；开发集 ID 唯一且完整 |
| 当前划分 | `data/splits/three-fold/` 的七个成员 JSON；读取 test ID 仅用于隔离，不访问测试媒体 |
| ROI 记录 | `data/roi/manifest.json`；开发集来源、输出摘要和决定身份必须对应 |
| 源视频 | `data/videos/<视频ID>.mp4`；现场核验 SHA-256 |
| ROI 视频 | `data/roi/videos/<视频ID>.mp4`；现场核验 SHA-256 和逐帧时间信息 |

输出目录必须显式指定；新运行拒绝已有目录，只有输入和代码身份一致时才能显式恢复：

```text
<输出目录>/
├── manifest.json              # 输入身份、逐源原因、窗口、裁剪结果及审核边界
├── summary.json               # 源、候选、成功、失败、角色和时长汇总
└── videos/<候选ID>.mp4         # 通过媒体核验的初步片段
```

记录应进入 Git，视频留在 Git 外。源视频、ROI 和既有输出都不会被覆盖；临时编码成功并通过检查后才原子建立最终文件。中断后可显式恢复；无记录的同名输出会阻止恢复，需要先核实，工具不会认领或覆盖它。

## 当前使用的规则

`geometry.py` 的纯窗口函数取自原项目 `2c272ce3548c917bbfa96fe474858f9bf1998893` 的 `pipeline/v3_candidate_plan.py`；内部几何辅助标签函数来自同提交的 `pipeline/v3_labels.py`。这是运行所需的功能代码，不包含旧 v4.1 发布契约或历史数据备份。

保留旧时长、事件位置、0.5 秒保护间隔、帧对齐、去重和各角色上限。历史审核参考没有与当前媒体绑定的可靠摘要，本工具使用旧函数明确定义的空参考回退，事件模板按 shift 0、1 排序，不宣称复现旧批次的历史参考排序。

初步收紧条件如下：

- 断裂状态、异常标注、旧机制映射不明确时跳过。未夹紧、视频异常和无法确定状态不生成片段。
- 断裂源须有可靠时间点、相邻的断裂前后帧；时间点须与第一分离帧和实际帧率对应。仅时间范围、单侧边界或不可靠时间均不猜测，保留原因。
- 现场读取全部帧时间戳；变帧率或无法证明源与 ROI 帧索引对应的输入跳过。严格跳过可能减少数量，不能据此认为源视频无用。
- 事件后片段另外要求：事件后保护间隔之外至少还有 2 秒源素材。它独立于旧的单候选最短 1 秒检查。

`legacy_geometry_labels` 仅说明旧规则如何选窗，不是当前五类片段标签。`labels_status=unassigned`、`manual_review=required` 表示最终标签仍须看片段后人工确认。所有拟发布片段都须人工审核，初裁不自动准入发布。

## 执行与恢复

完整视频处理在训练机执行；先核对机器状态、Python 环境、FFmpeg/FFprobe 及输入。工具使用 Python 3.10 以上标准库，项目实际执行仍遵守项目的 Python 环境要求。

先检查输入和规划窗口，不生成片段：

```bash
python script/subvideo_pilot/pilot.py --project-root /path/to/project --output-dir /path/to/new-output --plan-only
```

核对规划后，使用相同目录与代码执行初裁：

```bash
python script/subvideo_pilot/pilot.py --project-root /path/to/project --output-dir /path/to/new-output --resume
```

也可省略 `--plan-only` 在新输出目录直接初裁。输出目录里每个成功片段都保留源及 ROI 摘要、帧区间、三折归属和输出摘要。失败原因保留在清单，退出码 2 表示仍有已规划片段未裁剪成功；输入或身份错误退出码 1。

工具采用旧裁剪的逐帧 `trim` 和时间戳重置，CPU H.264、fast、CRF 23、yuv420p、无音频，并核对输出帧数、分辨率、帧率、时长和完整解码。它没有运行旧模型的 8 帧采样门禁，也不证明视觉标签正确或模型效果。

```bash
python -m pytest -q script/subvideo_pilot/tests
```

**失效条件：** 当前输入位置、划分、来源、ROI 媒体、时间锚点、旧窗口功能代码或收紧条件变化时，重新核对身份和受影响结果；新规则经用户审查后另行生成，不覆盖本轮初裁。
