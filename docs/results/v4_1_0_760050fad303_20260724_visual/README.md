BF16 的逐样本等价替代。

## 35 条 BF16 非法输出归因

35 条 strict-invalid 具有相同根因：

- 全部漏掉必填字段 `special_case`；
- 运行异常为 0；
- token 上限命中为 0；
- 生成 token 数为 28 或 30；
- 其余三个字段形成可解析 JSON，但四字段契约不完整。

按目标状态：

| 目标状态 | 数量 |
| --- | ---: |
| 未断裂 | 10 |
| 临界未断裂 | 10 |
| 发生断裂 | 13 |
| 已断裂 | 2 |

结论：这是模型首轮输出的契约退化，不是截断、CUDA、运行时或解析器误报。严格评估
继续将其判为非法；解析器不得自动补 `special_case=null`，否则会掩盖模型缺陷。
