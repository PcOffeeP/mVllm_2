# 断裂标签说明

**状态：后续标签标注基准文档，2026-11-05 用户指定。** 五类标签及状态、模式、位置、异常的名称方向已获用户认可；断裂现象名称为暂定词表，细化判据和跨类别填写规则仍待确认。本文作为后续标注标准的基准，不表示待确认细则已经定稿、现有代码已支持或获得批量改标授权。现行 v4.1 保持冻结，v4.2 实施仍暂停，见[未结事项登记册](pending-blockers.md)的 PB-019。

**何时作废：** 用户明确用新的权威标注规范取代本文或取消本标准时，本文作废；应保留的设计事实按项目规则并入 `docs/design-facts.yaml`，或删除本文，避免并存两套有效规范。

## 1. 标签类别分别回答什么

- **断裂状态：** 当前片段中，试样尚未分离、正在发生分离，还是已经分离？
- **断裂模式：** 有哪些证据支持断裂表现为脆性、韧性或两者兼有？
- **断裂位置：** 断裂处相对标距和夹持区域在哪里？
- **异常：** 是否存在本项目需要单独记录的夹持、视频或爆炸性断裂情况？
- **断裂现象：** 实际看到了哪些变形或破坏形态？可以多选，也可以出现在整体断开之前。

默认依据是**当前提供的片段**。若某项标注依据整条源视频，必须明确注明“整源”；不能把整源后续画面当成当前片段里已出现的证据。专业断口资料、力学曲线等补充证据，只有任务明确提供并允许使用时才纳入，且须注明来源。

## 2. 各类标签的完整名称

| 类别 | 标签名称 | 选择方式 |
| --- | --- | --- |
| 断裂状态 | 未断裂、发生断裂、已断裂、无法判断 | 单选 |
| 断裂模式 | 脆性、韧性、半脆半韧、无法确定 | 单选；适用条件仍待细化 |
| 断裂位置 | 标距内、标距外非根部、夹持根部、无法确定 | 单选；区域交界与多处断裂的规则待确认 |
| 异常 | 未夹紧、视频异常、爆炸性断裂 | 是否允许多选、如何与其他类别并存待确认 |
| 断裂现象 | 伸长、颈缩、开裂、纵向劈裂、层间分离、束状散开 | 固定名词多选；本行名称与范围暂定 |

“临界未断裂”已退出本稿的核心断裂状态：尚未整体分离但可见变化时，可用“未断裂”配合现象标签表达。这不直接改写冻结 v4.1；其现行契约仍有五值和事件方向语义，见[现行设计事实](design-facts.md)的 DF-001（active）。

## 3. 断裂状态

以下是本项目的**候选视频判读定义**，不是材料试验标准规定的状态词表。

| 标签 | 含义与边界 |
| --- | --- |
| **未断裂** | 清楚、连续的画面支持试样仍连通，当前片段没有出现整体可见分离。可以已有伸长、颈缩或局部裂缝；不能只因“没拍到断开”就判未断裂。 |
| **发生断裂** | 当前片段内能确认试样从仍连通变为首次可见分离。局部裂缝出现、突然抖动或只见断后形态，都不能单独证明该事件发生在片段内。 |
| **已断裂** | 可靠画面从一开始就已分离，片段内没有断裂前仍连通的证据。此处保留现行首帧锚点的含义，见 DF-002（active）。 |
| **无法判断** | 遮挡、模糊、缺帧或取景不足等原因，使以上三者无法可靠区分。它是看过材料后的不确定结论，不是“未标注”。 |

断裂事件仍以**可见分离第一帧**为锚点，不改成物理裂纹萌生时刻。[标签锚点标注规范](label-annotation-spec.md)及 DF-013（active）规定：`断裂帧_前` 是最后一帧仍连通，`断裂帧_后` 是第一帧已分离、也是权威值，时刻由实测 fps 派生。本稿的“开裂”等现象不改变这一锚点。

源表的“已标注·有断裂、已标注·无断裂、未标注、无法判读”描述**整条源视频的标注完成情况与可判性**，不属于上述片段状态。例如，整源已标注有断裂，其断裂前片段仍可为“未断裂”。

## 4. 断裂模式

[Bower《Applied Mechanics of Solids》断裂机制概述](https://solidmechanics.org/Text/Chapter9_1/Chapter9_1.htm)以断裂前塑性变形等特征区分脆性与韧性，并说明复杂复合材料可能难以简单二分。这里引用它支持**概念**；下面的中文标签及视频证据要求由项目定义，不是教材给出的官方词表。

| 标签 | 含义与边界 |
| --- | --- |
| **脆性** | 证据支持断裂前塑性变形很少。仅有“瞬间断开”不够；视频没拍出变形，也不能证明变形不存在。 |
| **韧性** | 证据支持断裂前有明显塑性变形。可见颈缩可以提供线索，但伸长可能含弹性变形或夹持滑移，不能单凭拉长就定为韧性。 |
| **半脆半韧** | 同一断裂过程有脆性和韧性两种特征，且能分别指出证据及对应部位或阶段。“拿不准”、先伸长后瞬断、分层与散束并存，都不足以单独支持本项。其具体证据门槛仍待确认。 |
| **无法确定** | 已判读，但证据不足、相互冲突，或只有断后形态，不能可靠归入前三项。不能把它当成漏填。 |

塑性变形证据的解释须适用于该材料和本次事件；必要时依赖可解释的卸载后残余变形、对应力学数据或专业断口判读，普通视频不能默认提供这些证据。断裂尚未发生时，模式是否记为“不适用”、怎样存储，仍待确认；**不新增“不适用”为模式名称，也不把它等同于“无法确定”**。

## 5. 断裂位置

标距是试验指定的测量长度范围，不能用“画面中间”代替。下面的三分区域及中文名称属于**项目定义**；判断前须有标距标记、试样图或其他可靠定位依据。

| 标签 | 含义与边界 |
| --- | --- |
| **标距内** | 断裂处能定位在已明确的标距范围内。只知道断在试样中部还不够。 |
| **标距外非根部** | 断裂处在标距范围外，同时不在试样伸出夹具的根部区域。 |
| **夹持根部** | 断裂处位于试样从夹持区伸出的根部，即夹持约束交界附近。“靠近夹具”本身不足以确定。 |
| **无法确定** | 已判读，但断裂处、标距边界或夹持根部无法可靠定位。不能按常见试样尺寸猜测。 |

未发生断裂时位置如何表示、断裂跨越区域边界或同时发生在多处时如何选择，均待确认。[ASTM D3039/D3039M 官方页面](https://store.astm.org/standards/d3039_d3039m)可用于确认该标准针对聚合物基复合材料拉伸性能；本文未核对其付费正文，不据此宣称上述区域划分、名称或试验有效性规则由 ASTM 规定。

## 6. 异常

“异常”是本项目的记录类别。尤其是“爆炸性断裂”归入异常，**不代表这种物理现象必然使试验无效**；数据是否排除另需明确规则。

| 标签 | 含义与边界 |
| --- | --- |
| **未夹紧** | 有明确证据显示夹持未形成有效约束，例如试样相对夹具滑移或脱出，并能排除试样伸长、断后回弹等解释。用户已确认此类**不标断裂模式和位置**；其片段状态与字段承载形式仍待确认。 |
| **视频异常** | 录制或画面问题影响判断，例如关键过程缺失、严重模糊、遮挡或试样出画。应说明哪些判断受影响；不能由局部看不清推定所有信息都不可用。 |
| **爆炸性断裂** | 候选含义是断裂伴随明显碎裂、多方向碎片飞散或大范围崩散，具体可见判据待确认。单次快速断开、两端回弹或少量束状散开，不单独构成本项。 |

上述异常名与判读边界为**项目定义**。空白不能自动当作无异常；“已查看未见异常”“看不清”“未标注”应分别表达，具体表示方式待确认。

异常是否多选、视频异常或爆炸性断裂与已见断裂如何同时填写、是否影响样本准入，均未由本文定案。可以保留已观察到的事实，不把未确认的跨类别规则写成强制组合。

## 7. 断裂现象

现象标签只记录**实际可见的形态或变化**，不自动说明微观机理、因果或脆韧性。本稿暂列以下常见名词，允许多选。

| 标签 | 看见什么才标 | 依据的性质 |
| --- | --- | --- |
| **伸长** | 试样自身可追踪特征沿加载方向的间距增大；排除整体平移、明显视角变化或单纯夹具移动。 | 项目视觉定义；不据此单独判断塑性。 |
| **颈缩** | 同一局部相对相邻部分逐渐变窄，能与初始外形、转动投影或遮挡区分。 | Bower 将颈缩列为韧性断裂常见特征；[NIST 载荷下衍射应力测量](https://www.nist.gov/programs-projects/ncal-diffraction-stress-measurement-under-applied-load)提及局部颈缩。来源支持概念，具体可见判据是项目建议。 |
| **开裂** | 可辨认新出现或继续扩展的裂缝、开口；不能把纹理、阴影或反光当裂缝。 | 项目视觉定义；不等于整体已经分离。 |
| **纵向劈裂** | 沿试样长度方向开裂，形成可辨认的条状或束状分离。 | 项目视觉定义；只见断口毛边、未见纵向延展时不强标。 |
| **层间分离** | 能辨认不同铺层之间张开或滑开；只是散开、但不能辨认铺层时，不强标。 | [NASA 层内与层间断裂韧性研究](https://ntrs.nasa.gov/citations/20120016494)区分两者，并以断口分析支持研究观察；它支持概念区别，不证明普通视频可鉴定微观损伤。 |
| **束状散开** | 宏观可辨的丝束或刷状部分散开。 | 项目视觉定义；不自动认定单纤维断裂、纤维拔出或界面脱粘。 |

不要自动联选：束状散开不必然有层间分离，开裂不必然是纵向劈裂。一般项与细分项能否共选、如何避免重复计分，仍待确认。

还要区分观察结果与填写进度：**已检查且画面足够、未见现象**，才能表达“无可见现象”；看不清是“无法判断”；没有完成检查是“未标注”。这些不是新增现象标签，具体表示方式待确认。已看见颈缩但后段被遮挡时，可以保留颈缩，同时注明后段无法判断；未勾选其他项不自动等于确认没有。

可选自然语言备注用于补充时间顺序、观察范围和限制，例如“断后才看见层间张开”。备注不能替代固定名词，也不能把先后关系写成已证实的因果。

## 8. 三个具体例子

以下都是**按给定条件构造的说明例子，不是对已复核视频或截图的结论**；只展示有证据支持的填写，未决组合仍保留待确认。

### 例一：瞬间断开，随后可见层间分离

假设当前片段清楚显示“仍连通 → 可见分离”，随后能辨认铺层之间张开，但没有脆韧证据或可靠位置参照。

- 断裂状态：**发生断裂**。
- 断裂模式：**无法确定**；断得快与层间张开都不足以证明脆性。
- 断裂位置：**无法确定**。
- 断裂现象：**层间分离**；若只见模糊散开，则不能强选本项。
- 异常：依实际证据另判，不能因瞬断就选爆炸性断裂。
- 可选备注：“断后可见层间张开，未确定断裂模式。”

### 例二：试样从夹具中滑出，没有证据显示试样断开

假设能明确区分试样相对夹具滑移与试样自身变形，看到试样逐渐脱出。

- 异常：**未夹紧**。
- 断裂模式、断裂位置：**不标**，遵守用户已确认的特殊规则。
- 断裂状态：未夹紧情况下的统一填法**待确认**，不能用空值或某个状态替它擅自定案。
- 断裂现象：不能把滑移当“伸长”；其他现象只按实际可见内容记录。

### 例三：出现颈缩，但片段内始终保持连通

假设片段足够清楚，局部相对相邻部分逐渐变窄，直到片段结束仍连通。

- 断裂状态：**未断裂**。
- 断裂现象：**颈缩**；若另有可靠伸长证据，可同时选伸长。
- 断裂模式、断裂位置：尚无已发生断裂可供归类，其“不适用”的填写形式**待确认**；不能为了填满字段而认定韧性断裂。
- 异常：按实际证据另判，颈缩本身不是异常。
- 可选备注：“当前片段可见颈缩，结束时仍连通；不推断后续是否断裂。”
