## 3. 字段覆盖能回答什么，不能回答什么

完整统计见文后的“附录 B：各划分字段原值分布”。统计对象是**源视频标注字段**，并非生成后的片段或训练样本。

| 读表口径 | 使用限制 |
| --- | --- |
| `无`、`无法确定`、`无法判断` 均保留原值；异常和现象分别统计各子字段。 | 不将固定“无”、不确定与未标注合并。 |
| 字段若为空，统计显示为 `空`。 | 不能据此自行补值、排除或纳入数据。 |
| 展示开发集、测试集以及各折 train/val 的字段条数。 | 不能直接当作片段标签或训练样本分布，也不能据此断定样本数量充分。 |
| 评价分母及各值的使用方式尚待确认。 | 与[评价设计](design-test.md)及任务台账 `EVAL-DESIGN` 同步决定。 |

附录中的源视频级统计还显示，部分划分缺少特定标签的正例：

| 划分 | 没有“是”正例的字段 |
| --- | --- |
| 测试集及 0、1、2 折验证集 | `异常_未夹紧`、`异常_爆炸性断裂`。 |
| 2 折验证集 | 另有 `现象_开裂`、`现象_断后脱夹`。 |

这些划分的源级标注本身无法提供相应正例识别表现的证据。它们也不能据以判断后续片段的标签覆盖或样本充分性，更不构成重新划分的依据；片段须按自身可见证据判断，评价可报告的范围仍需结合实际片段和已确认口径核定。

ID 对应也不等于素材身份和防泄漏检查已完成：

| 尚未覆盖的检查 | 为什么影响后续判断 |
| --- | --- |
| 重新比较新旧视频哈希 | 相同 ID 本身不能证明当前视频内容与来源一致。 |
| 不同 ID 间的重复或近似素材 | ID 不交叉仍不能排除素材跨划分重复或近似。 |
| 模拟数据来源 | 尚不能判断其是否与测试素材存在关联。 |

以上缺口需结合当前输入、来源记录及获授权的检查补齐；标注表与素材副本的历史核验范围仍以任务台账为准。

## 5. 建议怎样衔接，哪些仍待确认

**建议以原视频 ID 和固定划分清单为主索引。** 每个派生产物记录来源视频、所属划分、生成配置及人工审核结果；在生成任何片段前检查缺失、重复和跨划分冲突。

这样可延续当前划分并追溯同源片段；前提是先核实 ID 与素材身份，并明确异常、缺失项的处置。ID 一致本身仍不排除近似素材泄漏。**具体记录格式与冻结方式待确认，本文不据此修改接口。**

| 待决或待核查事项 | 当前明确的边界 | 还需要什么 |
| --- | --- | --- |
| 发现素材重复、近似或身份不符 | 保留既有划分是已确认方向。 | 若出现不同 ID 的重复或近似素材、素材身份不符或参考信息泄漏，依实际问题另行确认受影响条目的处置。 |
| 不确定与异常数据的使用 | 不能由当前统计自动纳入或排除。 | “无法判读”、各字段不确定及异常视频是否进入训练、验证或审查，与 `EVAL-DESIGN` 的评价分母同步决定。 |
| 时间信息与片段标签 | 时间类标签可用于子视频生成；模型不训练或评测时间类任务。下游须记录片段所属划分，源视频标签不能无条件复制到片段。 | 旧脚本仍使用旧标签与事件时间；新标签映射、选窗及具体代码适配继续讨论，不能由允许使用时间信息推导为旧实现已获确认。 |
| 后续测试安排 | 本次覆盖统计不开放测试，也不构成模型评价。 | 测试使用时机、候选准入及频率另行确认。 |
