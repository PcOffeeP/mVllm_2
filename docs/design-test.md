# 材料拉伸模型整体测评方案

## 1. 测评目标与范围

测评首先服务于辅助人工判断，同时考察五类标签预测、材料拉伸视觉信息识别、时序信息理解，以及抽帧是否提供了回答所需的信息。标签答对只说明输出与人工答案一致；要判断模型是否使用画面和顺序，还需要专门的对照实验。

模型的训练和日常预测保留五类标签：断裂状态、断裂模式、断裂位置、异常情况、断裂现象。测评可以另问证据选择或事件顺序问题，但这些诊断答案不自动成为训练标签。已有断裂帧和时间记录可帮助定位、核对候选画面，最终答案依据人工复核的画面；不训练或评价模型预测断裂帧、断裂时间的能力。

整体方向、固定真实来源与虚拟补充方式已由用户确认。本轮已确认五类输出编码、逐项准确率和召回的分母、精确率、多选误报率、五类全对口径、失败与未知的分列、跨字段冲突处理，详见第 3、6 节。其他未列明的补充统计、实验制作方法和记录结构仍是供审阅的设计建议。审核工作台和五类评分器已实现并开展合成验证；这不表示测评数据已构建或模型已验证，具体工具状态与限制见第 6 节。暂不设通过阈值，也未决定视觉、时序结果是否作为模型筛选的必要条件。模型独立使用，以及是否帮助人工提高质量或节省时间，需要另行验证。

## 2. 测评数据与来源划分

### 2.1 所有候选模型共用固定测评数据

保留现有 89 个真实开发来源的三折划分和 21 个固定测试来源，另外构建固定虚拟测评数据。基础模型、真实视频微调模型、虚拟视频微调模型、混合训练模型及不同基础模型，均使用同一版本的固定测评清单、问题和评分规则。真实与虚拟结果分别报告，不合成一个掩盖两者差异的总分。

| 数据 | 用途 | 使用边界 |
| --- | --- | --- |
| 真实开发来源及对应子视频 | 训练、验证、试验题目和调试评分 | 每折模型只在该折未用于训练的验证来源上评价；开发结果不冒充固定测试结果 |
| 现有 21 个真实测试来源及后续审核的测评片段 | 集中比较冻结候选 | 有历史测试使用记录；不用于反复修改提示词、训练或挑选数据 |
| 虚拟试制数据 | 检查生成、标注、抽帧和诊断方法 | 可以反复调整，但不能因此称为冻结测评数据 |
| 冻结虚拟测评数据 | 补充受控视觉、时序诊断 | 来源与训练、开发隔离；冻结后不用于训练或调参 |

以原视频为来源单位，以子视频为基本预测样本。某折训练原视频生成的子视频用于该折训练；验证原视频生成的子视频用于该折验证。同一原视频切出的许多子视频仍来自同一次试验。三折的验证来源不同，汇总时保留折号和对应模型，不能把其他折曾训练过该来源的模型结果混入。

固定的是视频、问题、人工答案与评分版本。模型采用不同加载方式时，实际收到的帧可能不同，因此还要记录各模型的输入；这类跨模型比较反映模型与输入配置的整体表现。

### 2.2 现有数据能支持的结论

[本轮划分结果](split/data-split-result.md)记录：固定测试来源的人工标注中，未夹紧、爆炸性断裂、开裂没有正例；开发侧相应正例只有 1、2、3 个独立来源。虚拟视频可补充这些现象的诊断，不能补出真实实验来源，也不能证明模型已在这些真实现象上得到验证。

此前曾从 89 个开发来源中的 67 个生成 1,123 个候选片段，继承既有三折；21 个测试来源未参与生成。该批在最终片段标签、人工审核、模型采样检查和发布前已按用户要求删除，不能作为当前训练、验证或测评数据。后续生成规则见[当前子视频生成逻辑](subvideo-current-logic.md)，新批次仍须另行验收。

固定测试集已有历史使用记录；重新切片不会使它变成从未使用过的独立测试集。真实来源的完全重复检查不能排除近似素材，虚拟与真实素材的参考关系仍需核查。依据见[划分设计](split/data-split-design.md)、[划分结果](split/data-split-result.md)和事实记录 DF-020。

### 2.3 来源关系与训练隔离

每个真实原视频、虚拟场景及派生片段都记录父来源。由同一虚拟场景生成的正负配对、遮挡、倒序、视角或参数变体归入同一来源组，不能分到训练和固定测评两边。

虚拟场景如果直接参考某个真实实验，应记录真实来源及参考内容。参考固定真实测试来源的场景及其派生素材不得用于训练或开发调参；若真实来源是某折验证来源，参考该来源的虚拟场景及其近似变体也不得进入该折模型的训练。训练来源的近似复现不能被当作独立测评素材。通用资产的共享和具体实验的复现分开记录，核查是否存在足以泄露答案的相似几何、纹理、背景或运动。来源不清楚时保留疑问，不先认定独立。

先审计已有训练素材与拟选测评来源，再冻结清单。后续发现交叉时保留问题和受影响模型身份，不能只删除一份重复文件便宣称训练暴露已消除。具体来源组字段和近似素材判定方法仍须结合素材确认。

已有虚拟视频中，参考固定 test 来源 `video_0025` 的 1 条和 `video_0032` 的 11 条，共 12 条，保留为未来测评的待核候选；禁止训练和开发调参。纳入前须核查各候选模型的历史暴露、来源关系，并由用户逐片观看、按本轮标签审核；不能算作新增独立真实来源，也不因保留候选而准入冻结测评。

## 3. 五类标签的预测统计

### 3.1 人工答案和评分对象

完整片段的五类人工标签依[标签说明](label.md)填写；原视频标签只作参考。对诊断样本，另请人工查看模型实际收到的画面，记录证据是否充分及对应问题答案。

已确认并列报告两项：一是模型对完整片段人工标签的端到端结果，二是仅依据实际输入画面可否判断、模型回答是否得到画面支持。例如完整片段含断裂事件，而抽样帧只有断后画面，前一种结果会暴露输入链路的问题，后一种帮助区分信息不足和模型识别错误。两项平行报告，不能混算；抽样帧无法支持原片段状态时，不强行赋予确定的输入真值。输入证据不足的样本仍保留在端到端结果中，不得为提高能力分数而悄悄剔除。

### 3.2 三类单选标签

| 类别 | 合法取值 |
| --- | --- |
| 断裂状态 | 未断裂、发生断裂、已断裂、无法判断 |
| 断裂模式 | 脆性断裂、韧性断裂、半脆半韧断裂、无法判断、无 |
| 断裂位置 | 标距内、标距外非根部、夹持根部、无法判断、无 |

人工“无法判断”是有效判断，模型输出相同值可计正确。“无”按未断裂或未夹紧等固定组合适用；人工与模型同为“无”时正常计分，不把它解释为一种物理断裂模式。位置是视频中的相对位置分类，不表示测得精确工程标距；典型样例校准应先用非测试来源完成。

已确认逐类准确率和召回采用以下分母：“有效样本”指该类人工标签有效且请求已经尝试的样本，包含请求失败、缺字段和无法提取；尚未处理、人工未标分别另报。模型明确输出“无法判断”与缺失或失败分开；人工标签确定而模型不确定时不算正确，仍在对应分母。精确率已确认为补充统计：在模型明确报出某标签且人工可比较的样本中，计算报对的比例；单选模型“无法判断”是有效预测类别，在该类别精确率中正常比较，失败、缺失另列。多选模型“无法判断”不算明确“是／否”，数量另列。

| 指标 | 计算方式及状态 |
| --- | --- |
| 整体正确率 | 模型标签与人工标签相同数 ÷ 有效样本数 |
| 标签 c 的识别比例（召回） | 人工为 c 且模型正确报 c 的数量 ÷ 人工为 c 的有效样本数 |
| 标签 c 的报出正确比例（精确率，已确认） | 人工为 c 且模型报 c 的数量 ÷ 模型报 c 且人工标签有效的数量 |
| 混淆情况 | 按人工标签与模型标签列数量；缺字段、不可提取和请求失败另列，不能从总覆盖中消失 |

例如人工标为“发生断裂”的样本中，模型报成“已断裂”和请求失败均不是识别成功，但应区分两种原因。精确率只描述实际报出某标签的正确程度，必须同时展示输出失败数，不能只靠高精确率评价一个经常失败的模型。

### 3.3 两类多选标签

异常逐项评价未夹紧、视频异常、爆炸性断裂；现象逐项评价伸长、颈缩、开裂、界面分离、断后脱夹。断后脱夹不自动等于未夹紧；旧标注缺项也不当作“否”。

已确认异常和现象均逐项编码为“是／否／无法判断”。只提取模型明确表达的值；未提到某项不能推成“否”，缺字段不能当作完整负例列表。模型明确“无法判断”与缺失、提取失败分别记录。例如明确回答“开裂无法判断”时，保留该项为“无法判断”，不猜成有或没有裂缝。

对每项，人工“是”、模型“是”记 TP；人工“是”、模型明确“否”记 FN；人工“否”、模型“是”记 FP；人工“否”、模型明确“否”记 TN。模型未知、缺失或失败不伪装成 FN 或 TN，保留独立数量，但仍按下述已确认分母计为不正确。

- **逐项准确率：** 模型与人工相同数 ÷ 该项人工标签有效（“是”“否”“无法判断”）且已尝试的样本数。模型未知、字段缺失、提取失败及请求失败均留在分母。
- **识别比例（召回）：** TP ÷ 该项人工明确为“是”的已尝试样本数。正例中的模型未知、缺失和失败仍留在分母，单列其原因。
- **人工“无法判断”：** 自评分器版本 `five-label-score/2` 起是有效可比较类别，与单选字段的同类标签一致——真值侧记有效，纳入逐项准确率分母，并作为“无法判断”这一类参与逐类召回与逐类精确率；模型同样回答“无法判断”计该字段正确。空白未标另列，不影响其他有效项目评分；模型在未标样本中的回答保留，但不据此补人工真值。
- **数量与证据：** 逐项列正例、负例、人工“无法判断”、未标、模型“无法判断”、各类失败和未处理数，同时列涉及的原视频／虚拟场景数。没有正例或没有负例时说明相应证据不足。

已确认的多选顶层统计口径本轮未变：报出正确比例为 TP ÷（TP + FP）；多选误报比例为 FP ÷（FP + TN），只覆盖人工明确“否”且模型明确回答“是／否”的样本；识别比例仍为 TP ÷ 人工明确“是”的已尝试样本数。失败、缺失和模型“无法判断”另列，不进入这两个比例的分母，不能凭较高比例掩盖覆盖不足。异常优先关注漏报，同时报告误报。

上述顶层口径之外，本轮另加两类统计，与原指标并存但含义不同，不能互相替代或混读。一是三类逐类精确率：对“是”“否”“无法判断”各算一次，为“人工为该类且模型报该类数 ÷ 模型明确报该类且人工标签有效且已尝试数”；分母不按人工取值筛选，因此“人工为无法判断、模型报是”也进入“是”类精确率的分母（但不算正确），这正是它与上面 TP ÷（TP + FP）的差别，同一场景下两者数值可以不同。二是过度不确定率 `over_uncertain_rate`：模型答“无法判断”而人工为“是”或“否”的已尝试样本数 ÷ 人工为“是”或“否”的已尝试样本数，用于制衡“滥答无法判断”刷分；它单列报告，不进入任何综合分，也不改变其它指标的分母。

模型答“无法判断”时按人工真值分两种情形：人工同为“无法判断”，11 个叶字段都计为该字段正确，不计入失败／不确定单列；人工不是“无法判断”，则该字段在准确率（及适用召回）分母内计为不正确，其中**多选叶项且人工为“是”或“否”**的额外计入该字段的失败／不确定单列，单选字段从不做这种显式不确定失败计数。

### 3.4 特殊值、失败和补充统计

| 情况 | 处理原则 |
| --- | --- |
| 单选人工“无法判断”或适用的“无” | 按有效标签比较 |
| 多选人工“无法判断” | 按有效标签比较：进该字段准确率分母与“无法判断”类的逐类召回／精确率，模型同值算正确 |
| 人工未标注 | 不评分对应项目，不影响其他已有有效答案的项目 |
| 模型明确不确定 | 单列；与人工同值（同为“无法判断”）时计该字段正确（单选与多选同语义）；人工为其它确定取值（单选为该类确定标签、多选为“是”或“否”）时在准确率及适用召回分母内计为不正确，多选另计入失败／不确定单列 |
| 模型缺字段、提取失败、请求失败、超时 | 分别记录；不能算正确或当正常空列表；按上述已尝试样本口径保留识别分母 |
| 尚未处理 | 不算模型错误；报告固定批次清单中未处理数量 |
| 正例、负例或其他分母为零 | 对应比例写“无法计算／证据不足”，仍列实际数量 |
| 模型输出组合冲突 | 保留原回答，逐类按实际输出评分，另报冲突，不自动纠正 |

“五类全部正确比例”已确认为补充统计：分母为人工各项均可比较且请求已尝试的片段，分子为模型各项全对的片段。人工“无法判断”在单选与多选都是有效可比较标签，模型同值可算正确。**本比率含一项派生变更，随“多选人工无法判断改为有效类别”引出：**计算逻辑本身未改（分母仍是“11 个叶字段真值全有效且请求已尝试的片段数”），但人工“无法判断”在真值侧一律记有效，因此含多选人工“无法判断”的片段自评分器版本 `five-label-score/2` 起**进入**本比率分母，旧口径下这类片段被排除。任一字段人工未标注或无效时该片段仍不进入分母，不把未标当否来凑全对；模型缺字段或失败仍不能记全对。分母为零时报告证据不足，不用于自动晋级。

逐片段比例和逐原视频结果同时展示，避免片段多的少数原视频主导解释。按材料、设备和画质分组时列出来源数；独立来源很少时报告数量和个案，不据此声称稳定泛化。逐项准确率和召回分母按本节已确认规则执行；来源层的具体汇总方法、权重、其他未列明的补充统计及通过阈值仍待确认，不自行合成加权总分。

## 4. 对比实验

以下实验均须保留样本身份、实际输入、人工答案和原始回答。先在开发数据上验证题目是否能被人工一致理解，再冻结集中测评版本。

### 4.1 基础模型、微调模型与训练方案对比

每个可用基础模型与其微调版本在同一清单、问题和标注版本上配对比较；同一模型前后尽量固定抽帧、画面处理和生成配置。比较真实视频训练、虚拟视频训练、真实与虚拟混合训练时，记录数据量、标签覆盖、训练配置和资源消耗。三组从同一基础模型版本起步，开发时使用对应未训练来源，集中测试时共用冻结测评集。

分别比较五类标签、视觉诊断、时序诊断及失败情况。数据量、训练预算或输入配置不同时，结果只能说明整套训练方案差异，不能把提升全部归因于虚拟视频。不同基础模型采用各自可运行配置时，说明差异；若另做固定同一帧集合的受控比较，应与实际加载流程的结果分开。

可以用训练侧标签分布冻结“总报常见答案”等简单基线，检查类别先验。超过基线不等于理解画面或达到使用要求。对有代表性的样本重复运行，记录答案、失败和耗时变化；重复次数依资源另定，部分样本不代表全部稳定性。

### 4.2 视觉信息对照

首批方向已确认：以虚拟相似正负样本为主，并对部分样本比较原画面、关键区域遮挡和非关键区域遮挡，逐版由人工重核答案。以下制作与统计方法供审阅，具体场景、遮挡范围和验收细节仍需校准。无画面对照和证据画面选择作为可补充的诊断设计。

**无画面对照。** 对同一问题分别提供正常画面和仅文字。统计模型承认信息不足、仍报具体标签以及猜中原标签的情况。无画面本来就缺证据，不能把正常拒答直接解释成能力差；无画面猜中也不能证明识别了视觉信息。该结果帮助检查标签分布和文字线索。

**关键区域与非关键区域遮挡。** 在人工确认可见目标现象的样本中标出证据区域，保留原始输入；制作关键区域遮挡版和遮挡面积、方式尽量可比的非关键区域版。人工逐版重看，确认答案仍可判断、已无法判断或发生变化，再向模型提出相同问题。比较各版正确数、可判断数、失败数及同样本结果变化。遮挡可能造成异常外观或破坏其他证据，分数下降单独不能证明模型理解材料。

**相似正负样本。** 优先用虚拟场景固定试样、视角、照明等条件，构造目标现象可见的正例和外观接近的反例。例如开裂正例可见裂缝，反例有相似纹理或反光但画面足以确认无裂缝。人工若无法分辨，归入无法判断，不硬作负例。核对生成差异是否还带来背景、亮度、文件名等提示；让正负答案和这些非目标线索不固定绑定。记录两题各自正确率以及同一配对两题均正确的比例。同场景两题仍算一个场景来源，配对成功仅支持该组可见特征的区分。

**证据画面选择。** 在诊断输入的实际帧中询问“哪些画面支持颈缩／分离等判断”，人工预先标出可接受帧或多帧组合，包含没有充分证据的题。报告证据选择正确数、无证据误报，以及标签和证据同时正确的比例。候选帧编号不能泄露答案；文字解释流畅不能替代证据核对。候选帧形式和多帧答案匹配规则还需在开发侧校准。

### 4.3 时序信息对照

首批方向已确认：使用同一组画面的正反展示顺序配对，并以自然视频中人工可判断的事件关系补充。以下画面与问题是构建示例，具体样本、答案编码和验收方法尚未落定，也不表示已构建或测试。

**同画面、不同展示顺序。** 从实际抽样画面中选择人工确认的 A（连通）、B（分离），分别展示 A→B 和 B→A。两次都问“按展示顺序，先看到连通还是分离？”预期答案分别为先连通、先分离。画面不变，只改变顺序；其他问题文字和配置保持一致，记录原帧身份与展示位置，防止原时间戳或标签文字意外提示答案。

报告单题正确比例、两种顺序均正确的配对比例，以及答案是否正确跟随顺序改变。已尝试的配对中有一题失败，不能算配对全对；人工无法确定画面状态的题不用于这个确定答案比较，数量另报。B→A 只代表人为展示顺序，不能称作真实拉伸过程，也不沿用原视频五类标签评分。

**自然视频事件关系。** 在人工能辨认的实际输入中标注事件是否出现、可否判序，再问连通与分离、分离与断后脱夹等关系。答案依据该视频，允许事件未出现、接近同时或无法判断，不统一假设材料都经历伸长→颈缩→断裂。报告每种关系的正确数量、有效题数和来源数；缺少可判定关系时写证据不足。

可补充单帧、重复单帧和打乱帧的对照，先检查问题是否真的需要顺序。断裂位置等可能不依赖顺序，打乱后仍答对不说明模型不懂时序。打乱会改变题意或可读性时要重核人工答案，不能只用分数下降证明时序理解。

### 4.4 抽帧与输入覆盖

先单独核实本轮权重、处理器、加载入口、解码与采样规则，以及帧顺序和时间信息如何传入。旧 MiniCPM 路径和历史分组观察只作核查线索，不能当当前实际行为或能力结论，见事实记录 DF-016。该加载验证与正式材料测评分开开展。

为每次诊断保留实际选中的帧身份、顺序、可取得的时间参数，以及裁剪缩放等画面处理。人工查看可还原的实际输入画面，判定某问题所需证据充分、不足或无法确认。例如判断状态变化可能需要连通和分离两种画面，不能只查是否抽中某个精确断裂帧。

建议报告已确认所需证据的题中，输入证据充分的题数比例，同时列出不足和无法确认数量；按这三组展示模型结果。这个比例检查输入链路，不评价模型理解。人能够查看的输入图像与模型内部视觉编码也须区分，不能仅凭导出的代表截图声称完整还原所有内部处理。

## 5. 真实与虚拟测评数据的构建

### 5.1 真实视频及子视频

在既有划分上完成候选片段身份核对和人工审核。依据完整片段填写五类标签，覆盖断前、包含事件、断后等角色，同时检查它们在模型实际抽样画面中是否可见。源标签或自动窗口角色不能直接成为最终片段答案。

开发侧先校准标签、位置典型样例及诊断问题；正式测试样本的制作、审核和模型使用须另获实际操作授权。集中测评前冻结片段清单、问题和标注，不根据模型成绩挑掉困难样本。分别盘点每个标签的正例、反例、未知、片段数和原视频数，按可得到的材料、设备、视角、遮挡与画质条件检查覆盖，缺口如实保留。

### 5.2 虚拟视频先试制，再形成冻结集

首批先讨论以下试制候选。前三项各包括正例、易混淆反例和无法判断样例，共 9 个候选，用于检查生成、标注和输入方法，不是最终样本量，也不表示已经生成。

| 目标 | 正例需要呈现的证据 | 反例与无法判断候选 |
| --- | --- | --- |
| 未夹紧 | 可见夹持约束不足，试样相对夹具滑移或脱出，并能与自身变形区分 | 约束有效但试样伸长／断后回弹；关键接触处遮挡而无法确认 |
| 开裂 | 可辨认裂缝出现或扩展 | 相似表面纹理、边缘或反光但无裂缝；分辨率不足无法判读 |
| 爆炸性断裂 | 明显碎裂、多方向碎片飞散或大范围崩散 | 普通快速断开、两端回弹或少量散开；碎裂过程看不清 |
| 断裂模式 | 画面足以支持脆性、韧性或半脆半韧的现行定义 | 只有瞬断、拉长或分层而依据不足时，保留无法判断 |

表中爆炸性断裂仅列研究需求。旧 `full_span 0.2` 方案已被用户否定，制作继续暂停，不得因本文列出候选或本轮开发授权而自动恢复；须提出有依据的新方案、经用户确认并另获媒体生成授权。若无法合理呈现必要画面，应记为暂不可用。仿真中指定了某种材料或失效模式，不等于视频已呈现可用于该标签的证据。

后续按五类标签逐步补充：断裂状态的不同阶段，位置与夹具的相对关系，伸长、颈缩、界面分离、断后脱夹及视频异常。现象是否出现由人工看画面确认，不能把渲染参数直接转换成答案；例如断后脱夹需要确认断裂及脱出关系，不能直接改标未夹紧。

建议构建流程为：

1. 为每组定义要检验的现象、易混淆外观及预期可见证据，并登记真实参考来源。
2. 方案经确认并另获媒体生成授权后，制作试制候选和配对变体，记录场景、随机参数、相机、材料外观及父变体；这些是生成记录，不是最终人工真值。
3. 人工检查运动和破坏形态是否合理、画面是否清楚，逐项标是、否或无法判断；证据不足的模式可填无法判断。
4. 用目标输入流程检查证据是否会被抽到；短暂事件、遮挡或低分辨率造成的信息缺口保留记录，必要时调整试制。
5. 检查文件名、背景、固定颜色、镜头位置或渲染瑕疵是否与答案绑定，制作可比反例并复核所有变体。
6. 方法在开发试制侧可用后，另选隔离来源构建冻结集，完成来源审计、人工答案和输入记录；冻结清单后才用于集中比较。

试制时若根据模型反馈调整场景，这些样本属于开发材料。冻结集与训练素材不能共享同一个场景来源或其近似变体。不同材料外观、视角、遮挡、画质和运动条件的组合，应按研究目标和生成可行性设计，先盘点覆盖再讨论最终规模，不用重复渲染同一场景凑独立来源数。

虚拟画面的纹理、运动、破坏和拍摄条件可能与真实实验存在差异。报告人工可接受与不可接受的比例及原因，并比较真实与虚拟上的同类结果。虚拟得分良好只支持已构造场景中的受控能力，不单独证明模型能够识别真实拉伸信息。

## 6. 测评专用记录与质量检查

记录仅附在选中的测评和诊断样本上，不要求全部训练片段增加证据标注。具体编码可在评分协议中确定，建议至少能够还原下列内容。

| 记录 | 必须能回答的问题 |
| --- | --- |
| 数据身份 | 来自哪个原视频／虚拟场景、哪个子视频及其变体，属于哪个划分和清单版本？ |
| 完整片段人工答案 | 五类标签是什么，哪些项无法判断或未标注？ |
| 诊断题与证据 | 问了什么，可接受答案和证据画面有哪些，事件可否判序？ |
| 实际模型输入 | 哪些帧以什么顺序送入，使用什么解码、画面处理和时间配置，证据是否充分？ |
| 对照关系 | 原始、遮挡、正负及顺序版本怎样对应，各版人工答案是什么？ |
| 模型与结果 | 基础权重、微调版本、提示词、生成参数、原回答、提取结果及失败原因是什么？ |

人工答案，以及能直接泄露答案的定位或证据标注，只留在评分记录中，不进入模型请求。模型请求可包含普通展示顺序、候选帧编号或经过冻结的时间输入，这些属于输入配置；应检查它们是否意外暴露答案，而非一律禁止时间信息。

人工先按定义看画面，再核对生成设定，减少预设标签影响。存在分歧时记录对象、原因和复核结论；只有一人复查不能当作独立标注者一致性证据。标注修正保留版本，让所有参与比较的模型用同一份修正答案重新计分。

已确认五类标签输出使用中文顶层字段“断裂状态”“断裂模式”“断裂位置”“异常情况”“断裂现象”；前三类为单值，异常情况为三项、断裂现象为五项的逐项“是／否／无法判断”。不使用省略项目的列表推导“否”。严格检查格式、类型和允许取值；固定提取规则在测评前冻结，只提取模型明确表达的内容，不借助人工答案补答，也不依据固定组合自动纠正模型原回答。保留原文、逐项评分，并单列跨字段冲突；本轮不把这些结果接入自动晋级或发布。诊断题具体格式仍待协议设计，人工诊断另报，不能算自动成功。

片段审核的独立记录、版本追踪及执行边界见[子视频审核与评价衔接](subvideo-review-workflow.md)。[审核工作台](../script/subvideo_review/README.md)和[五类评分器](../script/five_label_eval/README.md)已实现；主 Agent 已用原项目 `.venv` 的 Python 在稳定任务工作树统一最终复跑评分 13 项、审核后台 18 项和集成测试 12 项，43/43 通过，Node 合成 DOM 测试 1/1 通过且 JavaScript 语法检查通过，另经工作台浏览器合成操作验证。完整复跑日志在临时目录 `/private/tmp/tensile-subvideo-final-workbench-20261110/`，是临时记录、不是备份；测试文件运行前后摘要一致。原约 1,100 px 视频覆盖参考区的问题已修复；独立 reviewer 使用纯色编号合成视频，在 1051、1100、1200、1201、1225、1250、1275、1280、1281、1300、1440、820、390 px 共 13 种离散宽度复验，均无覆盖或横向溢出，粘性工具条和长 SHA 显示正常。该结果仅为合成界面复验，不证明所有连续宽度或真实媒体均已验证。真实片段人工审核、实际模型输入检查和模型运行均未执行。

评分器的 `build_manifest` 可从最新审核导出及用户显式选择的候选 ID 创建身份快照草稿，复制来源、摘要和选定修订，不自动选样或正式冻结；未确认项仍保留原状态。要重现清单锁定的旧人工修订，需通过审核工具 `export --all-revisions` 取得完整历史供评分器读取，不能依赖最新导出恰好含该修订。模型实际输入仍需另外的人审证据，不能由完整片段审核推导。身份快照和合成评分均不自动授权正式测评、发布或模型运行。

## 7. 结果报告与依据

### 7.1 报告需要呈现的结果

真实开发验证、固定真实测试、虚拟试制和冻结虚拟测评分别标明。每次比较列出：五类标签逐项结果，视觉与时序各项实验结果，实际输入覆盖，原视频／场景数、片段／题目数，未标注、无法判断、失败和未处理数。完整片段结果与实际输入诊断分列，避免将信息不足误写成已证实的模型缺陷。

模型差异保留同样本配对，说明差异是否集中在少数来源。冻结数据上没有正例的类别不报告虚假的零召回；来源很少的类别不因片段很多而宣称稳定。预测标签、视觉对照和顺序题各自支持有限结论，不能直接推出模型理解所有材料物理过程。

### 7.2 运行性能与复现

首个性能环境沿用拟定的 4090 训练机，实际使用前核对环境。记录从视频进入训练机到完整结果的单请求耗时，首次加载与稳定运行分开；逐个批量处理记录整批耗时、完成、失败、超时及已耗时间。常规与困难样本分列并说明选择依据，首轮不默认开展并发测评。

成功请求的耗时分布同时列成功数和总请求数；失败或超时不能从报告中消失。中断时列实际覆盖和未处理清单。显存不足、量化或其他配置改变都保留独立身份；模型或输入身份无法确认时，不将结果纳入可复现比较。

每轮留存数据与标注版本、模型权重、提示词、输入处理、评分规则、运行配置、原始回答、逐项结果和失败清单。正式运行前冻结候选和这些身份；不把每个中间模型都送入固定测评集。新权重另记新模型身份，旧 v4.1 指标、阈值和晋级结论不直接迁入。
