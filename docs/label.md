# 断裂标签说明

## 1. 标签类别分别回答什么

- **断裂状态：** 当前片段中，试样尚未分离、正在发生分离，还是已经分离？
- **断裂模式：** 有哪些证据支持断裂表现为脆性、韧性或两者兼有？
- **断裂位置：** 断裂处相对标距和夹持区域在哪里？
- **异常情况：** 是否存在本项目需要单独记录的夹持、视频或爆炸性断裂情况？
- **断裂现象：** 实际看到了哪些变形或破坏形态？可以多选，也可以出现在整体断开之前。

默认依据是**当前提供的片段**。若某项标注依据整条源视频，必须明确注明“整源”；不能把整源后续画面当成当前片段里已出现的证据。专业断口资料、力学曲线等补充证据，只有任务明确提供并允许使用时才纳入，且须注明来源。

## 2. 各类标签的完整名称

| 类别   | 标签名称                    | 选择方式                |
| ---- | ----------------------- | ------------------- |
| 断裂状态 | 未断裂、发生断裂、已断裂、无法判断       | 单选                  |
| 断裂模式 | 脆性断裂、韧性断裂、半脆半韧断裂、无法识别 | 单选；另可填写无对应值         |
| 断裂位置 | 标距内、标距外非根部、夹持根部、无法确定    | 单选；另可填写无对应值  |
| 异常情况 | 未夹紧、视频异常、爆炸性断裂          | 多选 |
| 断裂现象 | 伸长、颈缩、开裂、层间分离 | 多选    |

“临界未断裂”已退出本稿的核心断裂状态：尚未整体分离但可见变化时，可用“未断裂”配合现象标签表达。这不直接改写冻结 v4.1；其现行契约仍有五值和事件方向语义，见[现行设计事实](facts.yaml)的 DF-001（active）。

## 3. 断裂状态

以下是本项目的视频判读定义，不是材料试验标准规定的状态词表。

| 标签 | 含义与边界 |
| --- | --- |
| **未断裂** | 清楚、连续的画面支持试样仍连通，当前片段没有出现整体可见分离。可以已有伸长、颈缩或局部裂缝；不能只因“没拍到断开”就判未断裂。 |
| **发生断裂** | 当前片段内能确认试样从仍连通变为首次可见分离。局部裂缝出现、突然抖动或只见断后形态，都不能单独证明该事件发生在片段内。 |
| **已断裂** | 可靠画面从一开始就已分离，片段内没有断裂前仍连通的证据。此处保留现行首帧锚点的含义，见 DF-002（active）。 |
| **无法判断** | 遮挡、模糊、缺帧或取景不足等原因，使以上三者无法可靠区分。它是看过材料后的不确定结论，不是“未标注”。 |

断裂事件仍以**可见分离第一帧**为锚点，不改成物理裂纹萌生时刻。DF-013（active）规定：`断裂帧_前` 是最后一帧仍连通，`断裂帧_后` 是第一帧已分离、也是权威值，时刻由实测 fps 派生。本稿的“开裂”等现象不改变这一锚点。

整源断裂帧表与片段五类标签是不同记录，不能用片段状态替换整源标注状态或两列帧号；五类标签面向整源时应标明“整源”，并按当前对象范围判断。

源表的“已标注·有断裂、已标注·无断裂、未标注、无法判读”描述**整条源视频的标注完成情况与可判性**，不属于上述片段状态。例如，整源已标注有断裂，其断裂前片段仍可为“未断裂”。

## 4. 断裂模式

[Bower《Applied Mechanics of Solids》断裂机制概述](https://solidmechanics.org/Text/Chapter9_1/Chapter9_1.htm)以断裂前塑性变形等特征区分脆性与韧性，并说明复杂复合材料可能难以简单二分。这里引用它支持**概念**；下面的中文标签及视频证据要求由项目定义，不是教材给出的官方词表。

| 标签 | 含义与边界 |
| --- | --- |
| **脆性断裂** | 证据支持断裂前塑性变形很少。仅有“瞬间断开”不够；视频没拍出变形，也不能证明变形不存在。 |
| **韧性断裂** | 证据支持断裂前有明显塑性变形。可见颈缩可以提供线索，但伸长可能含弹性变形或夹持滑移，不能单凭拉长就定为韧性。 |
| **半脆半韧断裂** | 同一断裂过程有脆性和韧性两种特征，且能分别指出证据及对应部位或阶段。“拿不准”、先伸长后瞬断或仅看见分层，都不足以单独支持本项。无法分别指出可靠证据时填“无法识别”。 |
| **无法识别** | 已判读，但证据不足、相互冲突，或只有断后形态，不能可靠归入前三项。不能把它当成漏填。 |

塑性变形证据的解释须适用于该材料和本次事件；必要时依赖可解释的卸载后残余变形、对应力学数据或专业断口判读，普通视频不能默认提供这些证据。断裂状态为未断裂，或异常情况包含未夹紧时，模式填写 **无对应值**；这个固定值不表示断裂模式，也不等同于“无法识别”。

## 5. 断裂位置

标距是试验指定的测量长度范围，不能用“画面中间”代替。下面的三分区域及中文名称属于**项目定义**；判断前须有标距标记、试样图或其他可靠定位依据。

| 标签 | 含义与边界 |
| --- | --- |
| **标距内** | 断裂处能定位在已明确的标距范围内。只知道断在试样中部还不够。 |
| **标距外非根部** | 断裂处在标距范围外，同时不在试样伸出夹具的根部区域。 |
| **夹持根部** | 断裂处位于试样从夹持区伸出的根部，即夹持约束交界附近。“靠近夹具”本身不足以确定。 |
| **无法确定** | 已判读，但断裂处、标距边界或夹持根部无法可靠定位。不能按常见试样尺寸猜测。 |

断裂状态为未断裂，或异常情况包含未夹紧时，位置填写 **无对应值**。断裂跨越区域交界、或多处断裂无法可靠归为同一区域时，填“无法确定”并备注观察情况。[ASTM D3039/D3039M 官方页面](https://store.astm.org/standards/d3039_d3039m)可用于确认该标准针对聚合物基复合材料拉伸性能；本文未核对其付费正文，不据此宣称上述区域划分、名称或试验有效性规则由 ASTM 规定。

## 6. 异常情况

“异常情况”是本项目的记录类别。尤其是“爆炸性断裂”归入异常，**不代表这种物理现象必然使试验无效**；数据是否排除另需明确规则。

| 标签 | 含义与边界 |
| --- | --- |
| **未夹紧** | 有明确证据显示夹持未形成有效约束，例如试样相对夹具滑移或脱出，并能排除试样伸长、断后回弹等解释。此类断裂模式和位置均填 **无对应值**；断裂状态仍按画面判断。 |
| **视频异常** | 录制或画面问题影响判断，例如关键过程缺失、严重模糊、遮挡或试样出画。以是否影响可靠判断为准；轻微画质问题不影响判断时不标。应说明哪些判断受影响；不能由局部看不清推定所有信息都不可用。 |
| **爆炸性断裂** | 断裂伴随明显碎裂、多方向碎片飞散或大范围崩散，以可见事实为依据。单次快速断开、两端回弹或少量束状散开，不单独构成本项。 |

上述异常名与判读边界为**项目定义**。异常可多选；视频异常、爆炸性断裂可与有画面证据的断裂状态和现象并存。是否排除样本由后续数据和评价规则决定。

已检查且能可靠判断未发现异常，记“无可见异常”；无法完整判断时记“无法判断”并备注无法判定的异常项；未完成检查记“未标注”。这些是填写状态，不是新的异常标签。若已发现部分异常但其他项看不清，保留已发现的异常并备注无法判定项。

## 7. 断裂现象

现象标签只记录**实际可见的形态或变化**，不自动说明微观机理、因果或脆韧性。首版固定以下四个名词，允许多选；“纵向劈裂”和“束状散开”按用户意见暂不列入。

| 标签 | 看见什么才标 | 依据的性质 |
| --- | --- | --- |
| **伸长** | 试样自身可追踪特征沿加载方向的间距增大；排除整体平移、明显视角变化或单纯夹具移动。 | 项目视觉定义；不据此单独判断塑性。 |
| **颈缩** | 同一局部相对相邻部分逐渐变窄，能与初始外形、转动投影或遮挡区分。 | Bower 将颈缩列为韧性断裂常见特征；[NIST 载荷下衍射应力测量](https://www.nist.gov/programs-projects/ncal-diffraction-stress-measurement-under-applied-load)提及局部颈缩。来源支持概念，具体可见判据是项目建议。 |
| **开裂** | 可辨认新出现或继续扩展的裂缝、开口；不能把纹理、阴影或反光当裂缝。 | 项目视觉定义；不等于整体已经分离。 |
| **层间分离** | 能辨认不同铺层之间张开或滑开；只是散开、但不能辨认铺层时，不强标。 | [NASA 层内与层间断裂韧性研究](https://ntrs.nasa.gov/citations/20120016494)区分两者，并以断口分析支持研究观察；它支持概念区别，不证明普通视频可鉴定微观损伤。 |

各现象只在有画面证据时选择；一个现象不自动推出另一个。发现词表外清楚可见的现象时可备注，集中复核后再决定是否扩充词表。

还要区分观察结果与填写进度：**已检查且画面足够、未见现象**，才能表达“无可见现象”；看不清是“无法判断”；没有完成检查是“未标注”。在现象栏分别记录“无可见现象”“无法判断”或“未标注”；这些是填写状态，不是新增现象标签。已看见颈缩但后段被遮挡时，可以保留颈缩，同时注明后段无法判断；未勾选其他项不自动等于确认没有。

可选自然语言备注用于补充时间顺序、观察范围和限制，例如“断后才看见层间张开”。备注不能替代固定名词，也不能把先后关系写成已证实的因果。

## 8. 填写规则

- 先确定标注对象是整源还是当前片段，记录对象及范围；每项只依据允许使用的对应画面和材料判断。
- 状态为“未断裂”时，模式和位置都填 **无对应值**；异常含“未夹紧”时，无论状态如何，模式和位置都填 **无对应值**。它是两个字段共用的固定值，不是空白、`NaN` 或材料断裂类型。
- 状态为“发生断裂”或“已断裂”时，模式、位置分别按证据选择；无法可靠辨认时分别填“无法识别”“无法确定”。状态为“无法判断”时，各字段仍按可见证据独立填写；不能确认有适用的断裂信息时分别填“无法识别”“无法确定”，不猜断裂发生或未发生。
- 异常、现象分别可多选。已完成检查且无可见项时用各自的“无可见异常”或“无可见现象”；看不清用“无法判断”；尚未检查用“未标注”。仅在能完整判断时才把未选项视作未见；部分可见时记录已见项，并在备注列出无法判定的项。不要将空白、`NaN`、无可见项或无法判断混为一谈。
- 单选字段未标注留空；不以空白代替“无对应值”“无法识别”或“无法确定”。可选备注记录现象时序、区域交界、多处断裂和观察限制，不能替代标签。
- 本文规定人工标注含义；具体表格列、JSON 编码及转换映射在后续接入时明确。旧 v4.1 导入器不能直接按本基准读取，应先完成新版本适配。

## 9. 三个具体例子

以下是按给定条件构造的说明例子，不是对已复核视频或截图的结论。

### 例一：瞬间断开，随后可见层间分离

假设当前片段清楚显示“仍连通 → 可见分离”，随后能辨认铺层之间张开，但没有脆韧证据或可靠位置参照。

- 断裂状态：**发生断裂**。
- 断裂模式：**无法识别**；断得快与层间张开都不足以证明脆性。
- 断裂位置：**无法确定**。
- 断裂现象：**层间分离**；若只见模糊散开，则不能强选本项。
- 异常：依实际证据另判，不能因瞬断就选爆炸性断裂。
- 可选备注：“断后可见层间张开，未确定断裂模式。”

### 例二：试样从夹具中滑出，没有证据显示试样断开

假设能明确区分试样相对夹具滑移与试样自身变形，看到试样逐渐脱出。

- 异常：**未夹紧**。
- 断裂模式、断裂位置：**无对应值**。
- 断裂状态：若能清楚看到试样始终连通，填 **未断裂**；否则按画面填 **无法判断**，不能仅由滑出推断断裂。
- 断裂现象：不能把滑移当“伸长”；其他现象只按实际可见内容记录。

### 例三：出现颈缩，但片段内始终保持连通

假设片段足够清楚，局部相对相邻部分逐渐变窄，直到片段结束仍连通。

- 断裂状态：**未断裂**。
- 断裂现象：**颈缩**；若另有可靠伸长证据，可同时选伸长。
- 断裂模式、断裂位置：**无对应值**；不能为了填满字段而认定韧性断裂。
- 异常：按实际证据另判，颈缩本身不是异常。
- 可选备注：“当前片段可见颈缩，结束时仍连通；不推断后续是否断裂。”
