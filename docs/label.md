# 断裂标签说明

## 1. 标签类别分别回答什么

- **断裂状态：** 当前片段中，试样尚未分离、正在发生分离，还是已经分离？
- **断裂模式：** 有哪些证据支持断裂表现为脆性、韧性或两者兼有？
- **断裂位置：** 断裂处相对标距和夹持区域在哪里？
- **异常情况：** 是否存在本项目需要单独记录的夹持、视频或爆炸性断裂情况？
- **断裂现象：** 实际看到了哪些变形或破坏形态？可以多选，也可以出现在整体断开之前。

## 2. 各类标签的完整名称

| 类别   | 标签名称                    | 选择方式                |
| ---- | ----------------------- | ------------------- |
| 断裂状态 | 未断裂、发生断裂、已断裂、无法判断       | 单选                  |
| 断裂模式 | 脆性断裂、韧性断裂、半脆半韧断裂、无法识别、无 | 单选         |
| 断裂位置 | 标距内、标距外非根部、夹持根部、无法确定、无    | 单选  |
| 异常情况 | 未夹紧、视频异常、爆炸性断裂          | 多选 |
| 断裂现象 | 伸长、颈缩、开裂、界面分离 | 多选    |

## 3. 断裂状态

| 标签       | 含义与边界                                                               |
| -------- | ------------------------------------------------------------------- |
| **未断裂**  | 清楚、连续的画面支持试样仍连通，当前片段没有出现整体可见分离。可以已有伸长、颈缩或局部裂缝；不能只因“没拍到断开”就判未断裂。     |
| **发生断裂** | 当前片段内能确认试样从仍连通变为首次可见分离。局部裂缝出现、突然抖动或只见断后形态，都不能单独证明该事件发生在片段内。         |
| **已断裂**  | 可靠画面从**一开始**就已分离，片段内没有断裂前仍连通的证据。此处保留现行首帧锚点的含义，见 DF-002（active）。 |
| **无法判断** | 遮挡、模糊、缺帧或取景不足等原因，使以上三者无法可靠区分。它是看过材料后的不确定结论，不是“未标注”。                 |

断裂事件仍以**可见分离第一帧**为锚点，不改成物理裂纹萌生时刻。

DF-013（active）规定：`断裂帧_前` 是最后一帧仍连通，`断裂帧_后` 是第一帧已分离、也是权威值，时刻由实测 fps 派生。本稿的“开裂”等现象不改变这一锚点。

## 4. 断裂模式

| 标签 | 含义与边界 |
| --- | --- |
| **脆性断裂** | 证据支持断裂前塑性变形很少。仅有“瞬间断开”不够；视频没拍出变形，也不能证明变形不存在。 |
| **韧性断裂** | 证据支持断裂前有明显塑性变形。可见颈缩可以提供线索，但伸长可能含弹性变形或夹持滑移，不能单凭拉长就定为韧性。 |
| **半脆半韧断裂** | 同一断裂过程有脆性和韧性两种特征，且能分别指出证据及对应部位或阶段。“拿不准”、先伸长后瞬断或仅看见分层，都不足以单独支持本项。无法分别指出可靠证据时填“无法识别”。 |
| **无法识别** | 已判读，但证据不足、相互冲突，或只有断后形态，不能可靠归入前三项。不能把它当成漏填。 |

断裂状态为未断裂，或异常情况包含未夹紧时，模式填写 **无**；这个固定值不表示断裂模式，也不等同于“无法识别”。

## 5. 断裂位置

| 标签 | 含义与边界 |
| --- | --- |
| **标距内** | 断裂处能定位在已明确的标距范围内。只知道断在试样中部还不够。 |
| **标距外非根部** | 断裂处在标距范围外，同时不在试样伸出夹具的根部区域。 |
| **夹持根部** | 断裂处位于试样从夹持区伸出的根部，即夹持约束交界附近。“靠近夹具”本身不足以确定。 |
| **无法确定** | 已判读，但断裂处、标距边界或夹持根部无法可靠定位。不能按常见试样尺寸猜测。 |

断裂状态为未断裂，或异常情况包含未夹紧时，位置填写 **无**。

## 6. 异常情况

| 标签 | 含义与边界 |
| --- | --- |
| **未夹紧** | 有明确证据显示夹持未形成有效约束，例如试样相对夹具滑移或脱出，并能排除试样伸长、断后回弹等解释。此类断裂模式和位置均填 **无**；断裂状态仍按画面判断。 |
| **视频异常** | 录制或画面问题影响判断，例如关键过程缺失、严重模糊、遮挡或试样出画。以是否影响可靠判断为准；轻微画质问题不影响判断时不标。应说明哪些判断受影响；不能由局部看不清推定所有信息都不可用。 |
| **爆炸性断裂** | 断裂伴随明显碎裂、多方向碎片飞散或大范围崩散，以可见事实为依据。单次快速断开、两端回弹或少量束状散开，不单独构成本项。 |

异常可多选；已检查且未发现异常时，记“无可见异常”。

## 7. 断裂现象

只标视频中实际看到的现象，可多选。

| 标签 | 看见什么才标 |
| --- | --- |
| **伸长** | 试样自身沿加载方向明显变长。 |
| **颈缩** | 试样局部相对相邻部分明显变窄。 |
| **开裂** | 试样出现或扩展可辨认的裂缝。 |
| **界面分离** | 能看见复合材料试样的各层之间明显分开。 |

## 8. 固定组合

CSV 的“断裂时间点”是人工标注字段，不作为模型微调的预测标签。

- **未夹紧**：断裂模式、断裂时间和断裂位置填“无”；断裂状态仍按画面判断。
- **未断裂**：断裂模式和断裂位置填“无”；确认完整视频未发生断裂时，`断裂帧_前`和`断裂帧_后`也填“无”。如果仅是片段未断裂，而完整视频后续发生断裂，前后帧仍按完整视频的实际断裂填写；无法判断完整视频是否断裂时，不因此填“无”。
- **无法判断**：画面不足以判断断裂状态时，状态填“无法判断”；模式和位置分别按可见证据填写，不能辨认时填“无法识别”和“无法确定”。
