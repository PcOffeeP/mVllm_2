# 断裂标签说明

## 1. 标签类别分别回答什么

- **断裂状态：** 当前片段中，试样尚未分离、正在发生分离，还是已经分离？
- **断裂模式：** 有哪些证据支持断裂表现为脆性、韧性或两者兼有？
- **断裂位置：** 断裂处相对标距和夹持区域在哪里？
- **异常情况：** 是否存在本项目需要单独记录的夹持、视频或爆炸性断裂情况？
- **断裂现象：** 实际看到了哪些变形或破坏形态？可以多选，也可以出现在整体断开之前。

## 2. 各类标签的完整名称

| 类别   | 标签名称                    | 选择方式                |
| ---- | ----------------------- | ------------------- |
| 断裂状态 | 未断裂、发生断裂、已断裂、无法判断       | 单选                  |
| 断裂模式 | 脆性断裂、韧性断裂、半脆半韧断裂、无法判断 | 单选         |
| 断裂位置 | 标距内、标距外非根部、夹持根部、无法判断    | 单选  |
| 异常情况 | 未夹紧、视频异常、爆炸性断裂          | 多选 |
| 断裂现象 | 伸长、颈缩、开裂、界面分离、断后脱夹 | 多选    |

片段层（本文件、审核工作台及评分器）不含模式／位置取值「无」；源标注层（`data/annotation-table-full.csv`、`data_split`、`roi`、annotation 工具）仍使用「无」。两层不得混用，也不得互相套用取值规则。

## 3. 断裂状态

| 标签       | 含义与边界                                                               |
| -------- | ------------------------------------------------------------------- |
| **未断裂**  | 清楚、连续的画面支持试样仍连通，当前片段没有出现整体可见分离。可以已有伸长、颈缩或局部裂缝；不能只因“没拍到断开”就判未断裂。     |
| **发生断裂** | 当前片段内能确认试样从仍连通变为首次可见分离。局部裂缝出现、突然抖动或只见断后形态，都不能单独证明该事件发生在片段内。         |
| **已断裂**  | 可靠画面从**一开始**就已分离，片段内没有断裂前仍连通的证据。此处保留现行首帧锚点的含义，见 DF-002（active）。 |
| **无法判断** | 遮挡、模糊、缺帧或取景不足等原因，使以上三者无法可靠区分。它是看过材料后的不确定结论，不是“未标注”。                 |

断裂事件仍以**可见分离第一帧**为锚点，不改成物理裂纹萌生时刻。

DF-013（active）规定：`断裂帧_前` 是最后一帧仍连通，`断裂帧_后` 是第一帧已分离、也是权威值，时刻由实测 fps 派生。本稿的“开裂”等现象不改变这一锚点。

## 4. 断裂模式

| 标签 | 含义与边界 |
| --- | --- |
| **脆性断裂** | 证据支持断裂前塑性变形很少。仅有“瞬间断开”不够；视频没拍出变形，也不能证明变形不存在。 |
| **韧性断裂** | 证据支持断裂前有明显塑性变形。可见颈缩可以提供线索，但伸长可能含弹性变形或夹持滑移，不能单凭拉长就定为韧性。 |
| **半脆半韧断裂** | 同一断裂过程有脆性和韧性两种特征，且能分别指出证据及对应部位或阶段。“拿不准”、先伸长后瞬断或仅看见分层，都不足以单独支持本项。无法分别指出可靠证据时填“无法判断”。 |
| **无法判断** | 已判读，但证据不足、相互冲突，或只有断后形态，不能可靠归入前三项。不能把它当成漏填。 |

断裂状态为未断裂或异常情况包含未夹紧时，模式按片段可见证据判断：能指出具体可见证据就填实际模式，指不出就填「无法判断」，不得按源标注或推测填写。

填具体模式或位置前，先过以下四条证据门槛（第 5 节与第 8 节引用同一组门槛）：

1. **能说出看到了什么**：例如断前可见颈缩及其位置、可见贯通横缝、可见分层剥离、能看清试样与夹口的相对关系。说不出具体可见证据时一律「无法判断」，不得按源标注或推测填写。
2. **片段时长与取景限制**：短窗口 `fracture` 片段可能只包含断裂时刻，看不到塑性变形。「没拍出变形」不构成脆性的证据，此时填「无法判断」，不要填「脆性断裂」。
3. **允许参考同源其他片段**：本片段证据不足时，可依据同源其他片段（例如该源 `pre` 长片段中看到伸长或颈缩）给出大致方向，但必须在「审核备注」写明依据的片段与现象，不得把同源片段看到的现象写成「本片段已见到」。
4. **未夹紧片段与未断裂同规则**：夹持失效本身不等于没有模式证据，按本片段可见证据填，指不出证据填「无法判断」。

## 5. 断裂位置

| 标签 | 含义与边界 |
| --- | --- |
| **夹持根部** | 断裂处明显位于试样伸出夹具的根部，即夹持约束交界附近。 |
| **标距外非根部** | 断裂处不在夹持根部，但明显偏向某一夹持端。 |
| **标距内** | 画面足以判断断裂处的相对位置，且不属于夹持根部或标距外非根部。 |
| **无法判断** | 画面不足以判断断裂处与夹具、试样的大致关系。 |

按表格顺序判断：先判断夹持根部，再判断标距外非根部，最后判断标距内。上下夹具都可见时，以两夹具之间可见的试样部分作为相对位置参照；断后回弹或滑落时，优先依据断裂发生时及其前后的画面判断。这里的“标距内”是视频视觉分类，不表示已测得精确工程标距。

断裂状态为未断裂或异常情况包含未夹紧时，位置按本片段可见证据判断，仍按「夹持根部 → 标距外非根部 → 标距内」顺序判读。

未断裂片段如果只能看清试样与夹具的相对关系，可据此给出大致方向（例如试样只在两夹具之间可见、未见根部或端部），并在「审核备注」写明依据；看不清则填「无法判断」。本条同样受第 4 节四条证据门槛约束，尤其第 3 条同源参考的备注要求。

## 6. 异常情况

| 标签 | 含义与边界 |
| --- | --- |
| **未夹紧** | 有明确证据显示夹持未形成有效约束，例如试样相对夹具滑移或脱出，并能排除试样伸长、断后回弹等解释。模式与位置按本片段可见证据分别判断，指不出证据填「无法判断」（见第 4 节证据门槛）；断裂状态仍按画面判断。 |
| **视频异常** | 录制或画面问题影响判断，例如关键过程缺失、严重模糊、遮挡或试样出画。以是否影响可靠判断为准；轻微画质问题不影响判断时不标。应说明哪些判断受影响；不能由局部看不清推定所有信息都不可用。 |
| **爆炸性断裂** | 断裂伴随明显碎裂、多方向碎片飞散或大范围崩散，以可见事实为依据。单次快速断开、两端回弹或少量束状散开，不单独构成本项。同一视频或片段中，爆炸性断裂与“未断裂”互斥。 |

异常和断裂现象均逐项判断、可多选：**是**表示已观看且有足够证据确认出现；**否**表示相关过程和部位足够清楚，能判断未出现；**无法判断**表示已观看但证据不足；**未标注（空白）**表示尚未完成该项判断。三项异常均填“否”，表示无可见异常。

## 7. 断裂现象

只标视频中实际看到的现象，可多选。

| 标签       | 看见什么才标                                                                  |
| -------- | ----------------------------------------------------------------------- |
| **伸长**   | 试样自身沿加载方向明显变长。                                                          |
| **颈缩**   | 试样局部相对相邻部分明显变窄。                                                         |
| **开裂**   | 试样出现或扩展可辨认的裂缝。                                                          |
| **界面分离** | 能看见复合材料试样的各层之间明显分开。                                                     |
| **断后脱夹** | 能确认试样已断裂，且在可见断裂的同时或之后，试样或其断裂部分从夹具中脱出。 此现象本身不证明未夹紧，未夹紧另按夹持证据判断；两者可以同时存在。 |

## 8. 固定组合
本节描述**片段层**（审核工作台与评分器）的填写规则。源标注层 CSV（`data/annotation-table-full.csv`）里的模式／位置历史取值不由本节重定义：其旧值可能仍是「无」，按第 2 节的跨层说明处理，审计时不套用本节规则。
CSV 的“断裂时间点”是人工标注字段，不作为模型微调的预测标签。

- **未夹紧**：断裂时间填“无”；断裂模式与断裂位置按第 4 节证据门槛判断，能指出可见证据就填实际值，指不出证据填“无法判断”。断裂状态按画面判断。若实际发生断裂，前后帧按可见的断裂画面填写。
- **未断裂**：断裂模式与断裂位置按第 4 节证据门槛判断：本片段能指出可见证据就填实际值，指不出证据填“无法判断”；本片段证据不足时可依据同源其他片段给出大致方向，并在审核备注写明依据的片段与现象，不得写成“本片段已见到”。确认完整视频未发生断裂时，`断裂帧_前`、`断裂帧_后`和断裂时间点也填“无”。如果仅是片段未断裂，而完整视频后续发生断裂，前后帧仍按完整视频的实际断裂填写。无法判断完整视频是否断裂时，断裂帧和时间点按可确认的证据填写。
- **无法判断**：画面不足以判断断裂状态时，状态填“无法判断”；模式和位置分别按可见证据填写，不能辨认时对应字段填“无法判断”。
- **断裂边界缺失**：已确认断裂时，可辨认的一侧填写对应帧号，缺失或无法辨认的一侧填“无”。视频首帧已可见分离时，断裂状态填“已断裂”，前帧填“无”，后帧可填 `0`，表示视频一开始就观察到分离。
- **帧号与时间**：帧号从 `0` 开始，用非负整数填写。前后帧均为数字时，前帧号必须小于后帧号。断裂时间点按数值后帧号除以实测帧率自动计算，单位为秒。后帧为 `0` 时，观测时间为 `0` 秒。非零后帧缺少有效帧率时，时间待核。变帧率视频用单一帧率换算的结果是估算值。未夹紧和确认完整视频未断裂仍按上述规则将时间填“无”。
- **帧号与时间列的“无”与模式／位置的取值无关**：`断裂帧_前`、`断裂帧_后`、`断裂时间点`、`断裂时间范围_下界`／`上界` 的“无”仍表示边界不可辨认或时间不可得，本轮语义完全保留。
- **标注完成**：选择“已标注·有断裂”或“已标注·无断裂”前，须填齐该记录的适用项，并通过各字段取值和组合规则的校验。异常和现象须逐项填写“是”“否”或“无法判断”。同一记录中，“发生断裂”或“已断裂”对应“已标注·有断裂”，“未断裂”对应“已标注·无断裂”。断裂状态为“无法判断”时，标注状态可填“无法判读”。尚未完成的记录可以保存草稿。
- **已有标注**：现行不确定取值为“无法判断”。标注页面登记四组历史写法，均按“无法判断”校验并保留原值供追溯：断裂状态、断裂模式、断裂位置三列各自的旧值“无法确定”，以及断裂模式的旧值“无法识别”。导入、恢复草稿和导出会保留这些原值，需要更新时可手动选择新名称。片段层旧固定值“无”不再作为断裂模式／断裂位置的合法取值：旧批次清单初值（835 条）的旧值仅在显示与预填层映射为“无法判断”并带提示；已存审核记录旧值回填时显示映射，记录需重审。清单与记录字节不改写、摘要不重算；源标注层的“无”仍是源层合法取值。

## 9. 断裂时间范围
以下为片段层记录规则；源标注层 CSV 同名列的历史取值不改写。
已确认发生断裂，但因遮挡、缺帧等无法确定精确断裂时间时，填写以下两列，单位为秒。能确定断裂帧或无需记录范围的视频，两列默认留空。

未夹紧的视频若能确认确有断裂，但断裂瞬间被遮挡，也可填写时间范围。断裂时间点仍填“无”；断裂模式与断裂位置按第 4 节证据门槛判断，指不出证据填“无法判断”。

| CSV 列 | 含义 |
| --- | --- |
| `断裂时间范围_下界` | 最后一张能确认试样仍连通的画面时间。 |
| `断裂时间范围_上界` | 此后最早一张能确认试样已分离的画面时间。 |

- 两端均可确认时，下界必须小于上界。只能确认一端时，填写已知时间，另一端填“无”，表示只有单侧边界。
- 边界时间按对应的源视频帧号除以实测帧率换算。变帧率视频用单一帧率换算的结果是估算值。
- 两端是限定断裂时间范围的画面证据。原有断裂前后帧和断裂时间点保留各自的含义及已有记录，范围中点不作为断裂时间点。
