# 子视频审核与评价衔接

**状态：2026-11-10，工具已实现并开展合成验证，真实片段人工审核尚未执行。** 独立本地审核工作台与五类评分器已完成实现，工作台也经过浏览器合成操作验证。原约 1,100 px 视频覆盖参考区的问题已修复并通过独立合成界面复验，具体检查宽度与限制见第 3 节；不能据此认定真实媒体或全部使用条件已验收。数据未发布，未运行真实模型，也未在本轮生成新媒体。

当前对象是统一批次重新生成后的 1,621 个候选子视频（开发集 1,307、固定测试集 314）；旧的 1,123 个候选批次已删除，本节涉及 1,123 的历史记录只描述该旧批次。技术记录可以说明文件和生成链路是否对应；最终片段标签必须由用户观看该片段后决定。源标注、窗口角色和虚拟生成参数均只作参考，不能充当片段真值。

## 1. 从候选到下一轮生成

本轮按以下顺序衔接，任何一环的通过都不能代替后一环：

1. **保留候选身份。** 对应源视频、ROI、片段、划分和生成版本；原标注保持原样。
2. **核对技术记录。** 检查清单、媒体摘要、生成规则和已有重放证据。失败或身份不一致的对象保留原因，不自动继承旧审核决定。
3. **用户逐片审阅。** 在独立本地页面播放候选，参考信息单独展示，用户填写五类标签，可保存草稿、退回或留下疑问。未完成审核的片段不发布。
4. **归纳问题。** 汇总标签难判、窗口缺证据、时间锚点、异常、来源及技术问题，保留受影响对象与已有记录；不在归纳时改标签或放宽规则。
5. **用户确认新规则。** 需要改变窗口、标签判据、数据用途等重大方案时，集中提供依据、收益、风险和待决项；不自动替用户选择。
6. **另获媒体生成授权。** 规则确认不等于生成授权。获授权后才按新版本生成下一轮，重新核对技术证据，再交用户逐片审核。

审核通过只表示该版本片段得到相应人工决定；后续训练／验证发布仍需明确的发布清单与验收。开发集三折归属随来源继承，不重划现有 21 个固定 test 来源。

## 2. 审核页面与人工记录

页面采用独立本地入口，支持候选播放、按来源与审核状态筛选，以及逐片确认五类；确认后自动进入下一个候选。草稿、退回、疑问和已确认分别保留，不能把“看过”或“保存草稿”写成审核通过。

**11 个可编辑字段默认按候选标签预填、确认前为草稿：** 断裂状态、断裂模式、断裂位置三个单选字段，以及三项异常、五项现象。单选取值与固定组合依[标签说明](label.md)；异常和现象逐项填写“是／否／无法判断”。空白表示未标，不能当“否”。旧清单初值的模式／位置“无”仅在展示和预填时映射为“无法判断”并提示；实测 10 个候选的最新修订含旧固定值“无”（历史共 11 条修订；`reviews.json` 当前工作树快照，统计于 2026-11-16），相关旧值作废，最新含旧值的候选须按新规则重审，记录字节不改写。预填值来自生成阶段候选标签，用户须逐项核对或修改后才确认；源标签仍只作另列参考，不参与预填，旧结论也不自动继承。

审核记录独立保存，不改原标注表。每条决定须能追溯到候选 ID、来源身份、片段媒体摘要、生成版本及所用标签规则；保存草稿、修改、退回和确认的版本关系。媒体、生成身份或标签规则变化时，历史决定保留为历史，本轮须重新确认，不能仅凭同名文件套用。实际启动、独立记录路径、保存和导出操作见[审核工作台说明](../script/subvideo_review/README.md)；使用时仍须核对本页列出的验证范围与限制。该记录文件 `data/subvideo-review/reviews.json` 纳入版本控制，审核后随提交保存；视频、本地锁文件与临时文件不进入版本库。

若用户认为参考值与画面不符，以本轮片段判断另记决定与理由。需要修改源标注或改变标签定义时，单独提出，不由片段审核回写。多人独立标注的一致性尚未验证，不能把本轮用户审核当作该项证据。

## 4. 真实事件与虚拟事件分别追踪

真实片段以[标签说明](label.md)的首次可见分离为事件锚点，原视频帧号、ROI 帧、片段帧和实际模型输入帧保留映射。整源时间记录用于定位与选窗，不预测或评价模型断裂时间。首帧已分离的观测时刻 0 不意味着物理断裂发生在视频起点。

虚拟视频的“最终失去贯通连接”是模拟事件记录，不能直接改写为人工首次可见分离，也不能由材料参数推导五类真值。记录真实参考源、虚拟父场景、变体、生成实现与媒体摘要；同一场景或其近似变体不能跨训练与固定测评两侧。倒序展示只作顺序诊断，不能称为真实材料重新连接或继承自然视频标签。

已有 65 条虚拟视频的调研中，1 条参考 `video_0025`，11 条参考 `video_0032`。这 **12 条保留为未来测评待核候选，禁止训练和开发调参**。纳入前须核查来源及各候选模型的历史暴露，由用户逐片观看并按本轮规则审核；它们不能当作新增独立真实来源。其余 53 条也不自动获得独立测评资格。未找到具体历史运行记录不等于已证明从未暴露。

旧爆炸性 `full_span 0.2` 方案曾被用户否定，生成继续暂停。列出爆炸性数据缺口不能恢复该方案；需要有依据的新方案、用户确认和另行媒体生成授权。当前不修改 Blender 项目。

## 5. 审核记录怎样进入评分

完整评分原则见[整体模型测评设计第 3、6 节](design-test.md)。五个中文顶层字段为“断裂状态”“断裂模式”“断裂位置”“异常情况”“断裂现象”；前三类单值，后两类分别含三项异常、五项现象，每项为“是／否／无法判断”。只提取模型明确表达的内容，不把未提及项目猜成“否”，不借人工答案补齐模型回答。

评分输入须绑定片段摘要、来源与真实／虚拟身份、划分、生成和人工审核版本，以及模型、Prompt、实际输入处理和评分版本。保留原始回答、逐项提取值、失败和未处理记录，避免拿不同输入或不同答案版本的结果直接比较。

- **准确率与召回：** 对应项目已尝试且人工有效的样本进入相应分母。单选人工“无法判断”是有效标签；模式／位置的旧值“无”无效，准确率、逐类召回／精确率及混淆矩阵只计人工状态为发生断裂／已断裂、该字段有效且已尝试的片段，排除片段的人工值分布单列不计比例；多选人工“无法判断”自评分器版本 `five-label-score/2` 起也是有效可比较类别，模型同值计该字段正确，并参与该类的逐类召回与逐类精确率。
- **未知、缺失和失败：** 模型明确不确定单列；缺字段、提取失败、请求失败和超时分别列出。人工有效且已尝试时，这些结果不算正确，但仍留在对应准确率和适用召回分母；未处理、人工未标另列。单选模型与人工同为合法不确定值时可计正确。
- **证据不足：** 没有正例或没有负例时，说明相应证据不足，不给出虚假比例。逐片段和逐来源分别呈现，真实与虚拟分开；精确率已确认按模型明确报某标签且人工可比较者计算报对比例；多选误报率已确认为 FP／（FP + TN），只覆盖人工明确否且模型明确是／否者，失败、缺失及模型无法判断另列。五类全对已确认使用人工各项可比较且请求已尝试者为分母；单选与多选人工“无法判断”都是有效可比较标签，模型同值可算正确，含多选人工“无法判断”的片段自 `five-label-score/2` 起进入分母；任一字段人工未标或无效时片段不纳入，模型失败不能全对；分母为零仍报证据不足，不用于自动晋级。来源汇总方法、权重、其他未列明的补充统计和阈值尚未定，不自行给加权总分。
- **跨字段冲突：** 保留模型原文，各项按实际输出评分，另列冲突；不按固定组合自动改正，也不接入自动晋级或发布。

[五类评分工具](../script/five_label_eval/README.md)已提供 `build_manifest`：用户显式给出候选 ID 后，从最新审核导出复制身份与修订，生成 `identity_snapshot_not_frozen` 身份快照草稿。它不自动扩选候选、不编造标签，未审、草稿、退回和疑问项仍保留原状态；即使全部已确认，也不自动正式冻结或批准数据用途。清单草稿入口使用最新导出，不接收全量历史来猜选修订。

评分器读取清单显式锁定的 `review_id`。重现旧人工修订时，须由审核工具 `export --all-revisions` 导出完整历史供评分器读取；最新导出只含当前身份的最新决定，可能不含被锁定的旧修订。实际模型输入仍需单独绑定请求、输入身份和人工证据记录，不能从片段审核或生成参数补造。

完整片段标签的端到端评价，与用户查看模型实际输入帧后的标签／可判断性平行报告。输入抽帧漏掉证据时，仍保留端到端样本；实际输入评价不强迫继承完整片段答案，也不能从代表截图推定已完整还原模型内部编码。当前未运行真实模型输入检查或正式测评。
