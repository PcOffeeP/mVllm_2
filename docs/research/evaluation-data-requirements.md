# 固定测评数据覆盖与虚拟数据制作建议

**状态：供用户审阅的调研与方案稿，2026-11-10。** 保留现有 21 个真实测试来源，用独立隔离的虚拟数据补充可控诊断，真实与虚拟分别报告。当前最明确的真实缺口是未夹紧、开裂、爆炸性断裂没有正例；源级没有“已断裂”，也不意味着以后审核的断后片段没有该状态。

本稿只完成文档调查与建议，不设最终视频数量、样本充分性门槛或模型通过阈值。没有处理真实测试视频、制作视频、运行 Blender、连接训练机或运行模型。**方案确认与实施授权分开：本稿不能恢复已经暂停的爆炸性制作，也不能直接启动其他制作或测试操作。**

## 1. 这些数据要回答什么

[整体模型测评设计](../../docs/design-test.md)已确认以五类标签为日常预测任务，同时检查模型是否利用画面、能否按展示顺序判断，以及实际抽帧是否提供足够证据。本稿把这一方向转换为数据要求，不替代正式评分协议。

真实视频提供实验场景下的直接证据；虚拟场景用于控制易混淆外观、可见性和展示顺序。虚拟诊断表现不能代替真实现象的验证，增渲同一场景也不能增加真实独立试验数。最终应同时知道某项有多少片段、多少虚拟场景和多少真实参考来源。

[标签说明](../../docs/label.md)是本轮五类标签的判读依据。单选与多选的“无法判断”均表示看过后证据不足（单选的历史写法“无法确定”已统一为“无法判断”）；空白表示尚未标注。固定文字“无”只按未断裂、未夹紧等组合适用，不是一种物理断裂模式。断裂时间与帧号只帮助定位画面，不增加时间预测任务。

### 2.2 这些数量意味着什么

未夹紧、爆炸性断裂和开裂的正例召回无法在这 21 个源标签上计算；明确负例仍可用于检查误报。界面分离、断后脱夹各只有 2 个正例源，夹持根部只有 1 个源，切出更多片段后也仍是这些来源，不能据此声称稳定泛化。伸长的 7 个“无法判断”不能改作负例来扩大分母。

源级“发生断裂”表示整段包含事件。后续从其中得到的断前、含事件或断后片段，应逐片重标：只有可靠首帧就已分离且片内没有断前连通证据，才标“已断裂”。当前源级 0 不预告未来片段数，也不能自动把时间窗角色当答案。

本轮已有的 1,123 个开发候选来自 89 个开发源中的 67 个；子视频结果记录了其画面对应检查及人工标签、模型采样和发布缺口（该旧批次结果文档已随提交 `9c54817` 删除，1,123 候选批次不再存在；已退役统一批次曾有 1,621 个候选（DF-027）；新批次规模以当前批次清单为准）。它们既不是本轮 21 个测试源的切片，也不是现成冻结测评集。测试媒体的制作、人工审阅和运行仍需对应授权。

## 3. 虚拟数据首先补哪些可见证据

建议按下表组织需求，而非先承诺每类几条。正例要求画面能支持“出现”，反例要求相关部位和过程足够清楚以支持“没有”；看不清时保留无法判断。每项都需同时审查其他标签，不能只把目标参数开关转成真值。

| 目标 | 正例所需证据 | 易混淆反例 | 无法判断候选 |
| --- | --- | --- | --- |
| 未夹紧 | 试样相对夹具滑移或脱出，且能排除自身伸长、断后回弹等解释，显示约束无效 | 夹持有效时自身伸长；断后回弹或脱夹但无独立失约束证据 | 接触区域遮挡，无法区分滑移与变形 |
| 开裂 | 可辨认裂缝出现或扩展；不要求已整体断开 | 接缝、纹理、划痕、边缘或反光与裂纹相似，但可确认不是裂缝 | 裂缝尺度、分辨率或遮挡使其不可辨 |
| 爆炸性断裂 | 与具体材料和结构相符的明显碎裂、多方向飞散或大范围崩散 | 快速普通断开、两端回弹、少量束状散开 | 关键破坏阶段缺失或看不清；不能凭参数确定 |
| 伸长 | 试样自身沿加载方向明显变长，有参照可排除相机或夹持运动 | 仅夹具平移、滑移或机位变化 | 参照或关键部位不可见 |
| 颈缩 | 同一试样局部相对相邻部位明显变窄 | 透视、整体缩放或固定几何细腰 | 局部轮廓不可辨或无法比较 |
| 界面分离 | 层合等适用结构的各层明显分开 | 表面线条、阴影或整体裂开但无层间分离证据 | 界面被遮挡、只有外轮廓 |
| 断后脱夹 | 同时有可见断裂和其同时或之后从夹具脱出的证据 | 保持夹持的断后运动；未断裂时滑移 | 断裂或脱出的关系不可辨 |
| 视频异常 | 关键过程缺失、严重模糊、出画或遮挡确实影响可靠判断 | 面积相近但不影响相关判断的非关键遮挡、轻微画质变化 | 对受影响的目标标签分别标不确定，不将全部标签一并作废 |

**断后脱夹不等于未夹紧。** 两者可同时出现，但各需独立证据。也不能把任何滑移都叙述成“初始未夹紧”；应记录出现阶段、相对运动对象和可排除的其他解释。

三类单选还需以下补充，不要求与全部材料做笛卡尔积：

- **状态：** 有清楚连通证据的未断裂、片内连通到分离的发生断裂、可靠首帧已分离的已断裂，以及过程不足以区分的无法判断。局部开裂仍连通不能标为整体已断。
- **模式：** 脆性需少量塑性变形的支持证据，韧性需明显塑性变形支持；仅瞬断或拉长均不足。半脆半韧须分别指出脆、韧证据和部位或阶段；不确定不硬分三类。
- **位置：** 同时呈现断裂处与夹具参照，覆盖标距内、偏向夹持端但非根部、夹持根部及位置无法判断。这里是视频相对位置分类，不冒充精确工程标距。

未断裂或已确认未夹紧时，模式、位置按现行规则填“无”；无效组合不通过虚构场景凑齐。制作错误先返工或剔出候选，不能只改标“视频异常”让错误成为合格样本。

## 4. 让模型必须看目标证据

### 4.1 相似正负配对与答案捷径

建议先在同一场景内固定试样、相机、光照与背景，只改变有依据的目标行为，形成可核查的正负配对。例如裂缝与外观相似纹理、滑移与自身伸长，应在同等可见性下区分。随后在不同来源约束的场景中检查这种区分是否仍成立。

正负答案不能固定绑定某种颜色、背景、夹具、材料名称、视频时长、事件固定时刻或渲染质量。文件名与题干不携带目标标签，帧编号只表示展示位置；来源 ID、人工答案及生成参数不提供给模型。检查非目标变化是否意外增加裂缝、改变亮度、造成跳帧或引入专属遮挡形状。可变外观不代表任意行为都能跨材料搬用。

同场景两题分别报告结果，并记录两题都正确的配对结果；配对仍只有一个场景来源。没有画面但猜中常见标签、或者标签正确却选错证据，都不能解释为理解画面。

### 4.2 关键与非关键遮挡

从人工已确认有目标证据的原版出发，分别制作关键证据区域遮挡版、面积和遮挡方式尽量相当的非关键区域版。人工逐版查看，重新判断五类标签和诊断问题：仍可判断、变为无法判断、或答案改变，并记录受影响项目。

遮挡版不能继承原版真值。即便遮住局部裂缝，其他帧仍可能提供证据；非关键遮挡也可能意外影响夹具参照。应按整个实际输入确认，不能只按遮挡坐标宣布证据已消失。遮挡可能引入新的异常外观，因此分数下降单独不足以证明模型依赖正确材料证据。

### 4.3 同画面正反顺序与自然事件关系

取人工确认的 A（连通）与 B（分离）画面，展示 A→B 和 B→A，问“按展示顺序先看到哪种状态”。两题图像集合一致，只交换展示位置；保留原帧身份以便复核，但不向模型泄露原时间戳或答案。检查模型答案是否正确随顺序改变，失败题不能计作配对全对。

**B→A 是人为展示顺序诊断，不是材料重新连接的物理过程。** 不给倒序组套原视频五类标签，也不作为自然拉伸视频训练或机制证据。正反序、遮挡和其他变体始终随父场景归组。

自然视频则逐条人工判断可见的事件及先后，如连通到分离、分离与断后脱夹。允许未出现、接近同时及无法判断，不统一编排“伸长→颈缩→断裂”。时间标注只定位候选，最终事件关系依据画面。

## 5. 先核对模型实际收到什么

完整视频和模型输入需各有一套人工核对结果：完整片段的五类真值用于端到端评价；实际抽帧、裁剪、缩放之后的画面用于判断问题是否有足够证据。抽帧漏掉断前连通状态时，不能强迫输入真值仍是“发生断裂”。

建议每个诊断样本保留实际帧 ID、源帧映射、展示顺序、可取得的时间参数、ROI 与缩放裁剪配置，并让人工检查可还原的实际输入。判断某事件关系可能需要多帧组合，抽中一个精确事件帧不自动表示证据充分。导出图像检查也不能证明完整还原模型内部视觉编码。

结果同时报告完整片段端到端表现，以及实际输入证据充分、不足、无法确认三组的数量与模型结果。**输入不足样本继续保留在端到端结果中**，不能为了提高能力分数静默剔除。按目标列片段数、独立场景数和真实参考来源数，并展示失败和未处理项；没有正例、负例或可判顺序的证据时明确写无法计算。

[事实记录](../../docs/facts.yaml) DF-016 描述旧 MiniCPM 加载与分组线索，不证明本轮运行行为或模型是否理解时序。各模型真实加载入口、权重、处理器和实际输入链必须另行核实；本稿没有执行这一验证。

所有参考真实测试来源的虚拟场景及派生变体，均禁用于训练和开发调参；这不限于上述已发现的 12 条。即使另行考虑它们用于虚拟测评，也须审查历史暴露、隔离、真实性与人工标签，并且不能视作新增独立真实测试来源。其余 53 条也不能自动判为独立测评素材：开发来源可能已用于训练、模板制作、选片、调参或人工试验，须核对模型和方案的实际历史暴露。若参考某折 val 源，其近似场景不得进入该折模型训练。

建议制作前登记关系：真实参考源 → 虚拟父场景 → 参数配置 → 正负/遮挡/顺序变体 → 实际片段与模型输入。保存场景 ID、父变体、实现版本、来源摘要、许可、参考内容与建模假设；同源、近似复现与共享通用资产分别记。随机种子、文件哈希或渲染角度不同都不足以使近似场景成为新独立来源。已经训练暴露的素材不能靠删除文件消除暴露，须保留受影响模型身份并限制结论。

## 7. Codex 与 Blender 后续怎样分工

未夹紧/滑移、关键与非关键遮挡、正反顺序诊断、背景等线索去关联及本轮五类标注交付，均未在本次证明为现成可用能力。不得直接套用旧入口命令，或借“补评测数据”绕过暂停决定。

### 7.2 建议的执行与验收顺序

1. **先形成场景说明。** Codex 整理目标、反例、可见证据、实际参考内容、未知和隔离关系；查明需沿用还是新增入口。缺少材料行为证据时先研究，不能让模型想象补足。场景方案及重大变化由用户确认，随后另获实施授权。
2. **制作有限试片。** 获授权后在 Blender 工作目录生成候选，记录源时间与模拟时间映射、配置与实现版本。按具体材料建模，不先铺大量交叉组合，也不预设最终规模。
3. **核查实际几何与视频。** 检查实际求值网格的夹口连接、连通性、事件顺序、适用长度/截面/体积、断后约束或衰减、间隙与穿透；核对最终编码、实际帧数、时间、视频与 JSON 一致性。不能只数预设组件或看进程退出码，也不为过门禁而擅自放宽容差。
4. **复核材料与画面标签。** 独立复核材料行为及证据，主 Agent 实际打开完整成片和关键阶段；人工逐片按五类规则标注，并逐个重看正负及遮挡版本。技术通过不能代替材料合理或用户看效果。
5. **检查实际模型输入。** 在另获授权、核对训练机和模型身份后，核查解码、抽帧及画面变换；让人工重核输入证据和可判事件顺序。未获运行授权时此步保持未执行。
6. **用户验收后才收录。** 提供成片、证据、预期/人工核验标签、来源和未知，由用户逐片确认效果及标签；接受后按 Blender 入口和索引规则收录。接受有限样片不等于接受连续参数范围或训练发布。

试制用于修方法，可以反复调整；最终冻结集需独立隔离，不直接把反复看过、改过的试制片换名算作未暴露测评。是否保留其为开发诊断、或只作过程记录，应在冻结清单中写明。冻结对象包括视频与摘要、来源关系、问题、人工答案、实际输入约定及评分版本；之后不因模型答错删困难样本。更换来源、题目或输入方法时另记版本和可比范围。

## 8. 科学资料能支持到哪里

已有实验优先，但来源能证明什么必须匹配材料、结构、加载与机位。下列公开资料可作为后续研究线索；本稿沿用本次资料核查提供的网页与附件入口信息，**没有播放其视频、审阅连续帧或完成素材许可与来源重合核验**，不据此赋予候选画面真值。

- [Namiki 等，2023](https://www.nature.com/articles/s43247-023-00816-3)：高温玻璃拉伸的不同条件下存在碎片与无碎片行为，可帮助研究碎裂边界；不能外推所有材料或替代复材的可见爆炸性依据。
- [Jiang 等，2020](https://www.mdpi.com/2073-4352/10/11/1047)：微缺口合金的原位裂纹扩展观察；过程含暂停，SEM 视野不能直接当宏观拉伸机位，后续需核对连续性和实际可见尺度。
- [Instron 夹持滑移说明](https://www.instron.com/en/resources/videos/2026/april/preventing-specimen-slippage-quick-tips-for-testing/)：官方视频与转录可帮助区分滑移和试样变形；尚未确认是否含可用完整实验录像，不能将一切滑移改写成初始未夹紧。

后续研究若找到充分视觉依据，也仍需单独提出新场景方案并申请实施；**研究提案不解除旧爆炸性候选的暂停**。若最终无法合理呈现某项，应明示该项暂不可用，不用闪光、附件运动或毛束散开替代。
