## 决定与使用边界

保留既有真实视频划分，先核对其与新标注的对应和覆盖，不能因整理工作区或文档自动重新划分。同源片段保持源视频的划分；发现身份或划分冲突时先报告，不自行重分配。

当前测试集有历史使用记录，不能描述成从未使用过的独立测试集。后续测试时机、候选准入与使用频率仍待确认；本记录及现有任务登记不提供 test 使用授权。当前 EVAL-DESIGN、DATA-HANDOFF 和迁移审查工作须继续遵守各自的数据使用范围。

## 理由与限制

本轮衔接以已有划分为输入，并核对新标签与它的关系。保留划分是现存材料明确记录的起点；本文没有重建当时选择保留划分的全部论证，也没有据此认定其样本分布、来源独立性或无泄漏已经验收。

当前按 ID 对应和字段覆盖的结果只能支持相应核查范围。不同 ID 是否存在重复或近似素材、模拟来源是否包含验证或测试信息等问题仍待查；源视频数量不能直接证明后续子视频及各划分样本充分。

若这些核查发现重大问题，应将冲突和影响交用户决定。保留既有划分并不授权忽略冲突，也不意味着已经确认重新划分。
