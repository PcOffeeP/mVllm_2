# DEC-004：片段层断裂模式与位置移除「无」

- **决策状态：已确认。** 用户于 2026-11-16 确认。
- **记录日期：2026-11-16。**
- **适用范围：** 片段候选展示、人工审核与五类评分。
- **实施状态：** `score.py`、`server.py`、`app.js`、`index.html` 已同步；`script/integration_tests/test_label_option_contract.py` 分别守卫片段层与源标注层。
- **验证状态：** 本记录不提供真实模型评价结果。

## 背景

「无」既不是断裂表现，也使未断裂／未夹紧片段的模式信息被系统性丢弃。

## 决定

片段层模式和位置移除「无」；未断裂或未夹紧时按可见证据填实际值，指不出证据填「无法判断」。四条共同证据门槛：能说出具体可见现象；短窗口没拍出变形不构成脆性证据；允许参考同源其他片段但审核备注须写明片段与现象且不得冒称本片段所见；未夹紧与未断裂同规则。详见 [标签说明第 4 节](../label.md#4-断裂模式)。

评分按人工断裂状态分层：模式和位置的准确率、逐类召回／精确率及混淆矩阵只计状态为发生断裂／已断裂且该字段人工有效、已尝试的片段；其余被排除片段单列人工取值分布，不计比例。

评分口径变更须先升版本，评分版本随之升为 `five-label-score/3`。

## 影响与不改的部分

835 条旧清单初值含「无」，只在展示／预填映射为「无法判断」并带提示，不进入任何摘要输入，清单字节不变。此前估算 18 条；只读实测当前工作树 `reviews.json`：10 个候选的最新修订含旧值、历史合计 11 条修订含旧值（共 19 条修订，最新时间 2026-11-16T06:21:36.318808+00:00）；相关旧值作废，最新含旧值的候选需重审，记录字节不改写、摘要不重算。prompt 新版本 v2 的摘要见 [prompt 版本记录](../eval/prompt.md)。

源标注层（`data/annotation-table-full.csv`、`data_split`、`roi`、annotation 工具）仍用「无」；帧号／时间列（`断裂帧_前`、`断裂帧_后`、`断裂时间点`、`断裂时间范围_*`）的「无」语义完全保留；生成层初值规则及 `manifest.json` 字节不变。
