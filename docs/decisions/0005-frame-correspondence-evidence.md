# DEC-005：帧对应抽帧取证

- **决策状态：已确认。** 用户已确认本设计。
- **记录日期：2026-11-23。**
- **适用范围：** 一次模型运行实际输入帧的四级对应关系与人工可查证据。
- **实施状态：** 设计已定（2026-11-23 原记录时未实现；独立取证 CLI 已于 2026-11-24 随 PR #21 落地于 `script/frame_correspondence/`，前置条件 1 已于 2026-11-25 经 [DEC-006](0006-eval-frame-sampling-and-model-lineup.md) 拍板，尚未在真实运行产物上执行；当前状态见[帧对应抽帧取证](../frame-correspondence-evidence.md)）。
- **验证状态：** 本记录不提供帧级重放结论。

## 背景

批次审计和单次运行回答不同问题：前者说明批次接受了哪一级核验，后者需要说明模型实际看到哪些帧及其来源。

## 决定

以本次实际输入帧为锚点，逐帧回溯子视频、ROI 与原视频，按次保留各级帧号、时间戳、媒体摘要和同刻画面。
对应关系与产物边界见[帧对应抽帧取证](../frame-correspondence-evidence.md)。

## 影响与不改的部分

取证独立于子视频生成与检查，不需要重生成批次，不改变 `basic`／`none` 的证明限制。
画面供人工查阅，不由 Agent 判相似，也不构成机器证明。

## 取代关系

本决定不取代既有审计分层；按次取证与 `full` 收据互不替代。

**失效条件：** 实现前置条件、映射表、锚点或证明强度口径变化时须重新核对。
