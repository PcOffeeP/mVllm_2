# 材料拉伸视频模型的验证与优化方向

## 文档定位

本文件是后续验证与优化工作的**方向登记与决策文档**，不是只服务于某一个
当前实验的执行清单。每当出现一个可检验的新想法，都可以直接在本文增加一张
“方向卡”，并说明其背景、假设、基本思路、准备工作、验证方法、风险和决策条件。

当前已经登记两条并列方向：

| 方向           | 要回答的问题                     | 当前定位      |
| ------------ | -------------------------- | --------- |
| A. 视觉归因验证    | 模型是否真的利用了试样和断裂过程的视觉证据？     | 前置验证工作    |
| B. ROI 裁剪与放大 | 减少环境干扰、放大试样后，是否提升可见性和模型表现？ | 数据/输入优化候选 |

它们不是唯一的后续路径，也不是按优先级固定的永久路线。新的方向可以是帧采样、
时间建模、双视图输入、训练样本构造、损失函数或评测方法等；每一项都应先在本文
中写清楚，再进入代码或训练实验。

## 方向 A：视觉归因验证

### A.1 背景

当前 prompt 测试已经表明，输出格式可被约束为四字段 JSON；但这不能证明模型
看到了断裂，也不能证明它理解了材料拉伸过程。模型重复输出 `未断裂` 可能来自：

- 断裂短暂或区域过小，模型实际接收的采样帧中没有足够证据；
- 视频缩放、整帧输入或背景占比过大，使试样细节被稀释；
- 基座模型缺少材料拉伸和断裂的领域视觉能力；
- 模型主要依赖语言先验、输出协议或数据分布，而非视频内容；
- 模型、processor、帧采样或视频输入链路与预期不一致。

因此，`JSON/schema 合法率`、`train_loss` 和 `eval_loss` 都不是视觉使用的证据。
它们只能说明格式或训练目标的拟合情况。

### A.2 基本思路与核心问题

后续工作应依次回答以下问题：

1. 模型实际收到的帧中，人类是否能够看见试样与断裂事件？
2. 在相同设备和背景下，模型能否区分“断裂前”和“覆盖断裂”的视频片段？
3. 改变、遮挡或替换试样视觉证据后，模型输出是否相应变化？
4. 微调模型是否比基座模型更可靠地利用试样区域，而非记忆背景、时长、裁剪
   名称或类别先验？
5. ROI 裁剪是否在不损失位置/夹具信息的前提下，提升上述能力？

只有这些问题获得正向证据后，才可以将模型称为是在分析材料拉伸视频。

### A.3 后续准备工作与验证路线

#### A.3.1 输入帧审计（前置门槛）

对每个代表性样本，导出**模型实际收到**的帧、帧索引、时间戳、分辨率和裁剪
信息，并生成 contact sheet。不能以原始视频替代这些证据。

审计集至少覆盖：

- 来自不同源视频的明确断裂正例；
- 明确未断裂负例；
- 未夹紧和视频异常；
- 断裂前、断裂附近和断裂后的子视频。

由人工检查以下内容：断裂前后帧是否都被采到、试样是否足够清晰、断裂位置是否
在可见区域、模型使用的帧索引是否与标注区间一致。

若人类无法在输入帧中可靠判断，必须先调整采样和 ROI，不应以 prompt 或训练
失败解释模型表现。

#### A.3.2 同源正负配对

从同一原始视频构造配对样本：

- A：断裂前片段，标签为未断裂；
- B：覆盖断裂事件的片段，标签为断裂；
- 条件：装置、背景、试样类型和大部分视觉上下文尽量相同。

同一固定 prompt 下，模型应对 A 输出未断裂、对 B 输出断裂。该配对比不同视频
间的总体准确率更能排除背景、设备外观和类别比例的混杂。

验收指标包括：配对翻转成功率、`has_fracture` precision/recall/F1，以及 B 中
`fracture_between` 与事件帧的命中率。配对必须按源视频隔离，不能将多个同源子视频
当作独立统计证据。

#### A.3.3 视觉反事实与消融

在不改变文字 prompt、模型权重和生成参数的情况下，对同一视频建立视觉对照：

| 对照    | 操作            | 期望观察            |
| ----- | ------------- | --------------- |
| 试样遮挡  | 遮挡标距区或断裂区域    | 断裂识别应明显受影响      |
| 断裂前截断 | 去除断裂后帧        | 断裂判断/时间定位应改变    |
| 帧顺序扰动 | 打乱时间顺序        | 时间区间定位不应保持原结果   |
| 无关帧替换 | 以等尺寸无关画面替换视频帧 | 不应保持对原断裂事件的正确判断 |

这些实验不要求模型在每种反事实下给出某个固定标签；重点是其输出是否对试样与
时间证据敏感。若真实视频、遮挡视频和无关视频的输出几乎不变，说明模型没有
显示出足够的视觉归因证据。

#### A.3.4 基座模型与微调模型的不同目标

基座模型的任务是建立能力下限：它能否从帧中观察到“连续性中断/两段分离”等通用
视觉现象。它不识别材料拉伸或细分断裂模式并不意外。

微调模型的任务更高：在未见过的源视频上，它应从相同装置/背景下的视觉变化中
识别断裂、定位时间区间、判断模式和空间位置。微调模型必须通过同源配对和视觉
反事实验证；训练 loss 下降不能替代这些验证。

### A.4 方向 A 的决策门槛

若输入帧审计显示人类也无法看到事件，应优先调整视觉输入，而非继续优化 prompt。
若同源正负配对、遮挡或无关帧替换都无法改变模型输出，则不能声称模型已经可靠地
使用了视频证据；应将此结论作为后续训练与输入优化的前置问题。

## 方向 B：ROI 裁剪与放大

### B.1 背景

整帧视频中常包含实验台、背景、仪器文字、人员和大面积空白。若试样和断裂区域
占比过小，缩放后的视觉 token 可能缺少足够的形变与分离证据。ROI 裁剪是针对
“关键信息像素占比不足、环境视觉信息可能干扰训练和识别”的输入优化假设。

### B.2 基本思路

ROI 版本应将视觉注意力集中到试样、标距区和必要的夹具关系，减少实验台、人员、
背景、仪器文字等无关信息。它的目标不是制造新的标签，而是提高关键形变和分离
证据在模型输入中的像素占比。

### B.3 后续准备工作：裁剪原则

1. 保留试样全长、标距区及两端必要夹具边界；不能只截取标距中央。
2. `inside_gauge`/`outside_gauge` 和齐根断裂依赖空间上下文；过度裁剪会破坏
   location 标签的可判别性。
3. 优先使用统一、可复现的几何规则或经人工审核的 ROI，而不是按标签手工裁剪。
4. 训练、验证和测试必须使用相同裁剪规则、分辨率和帧采样策略。
5. 原始媒体永远保留；ROI 视频作为版本化派生产物，不能覆盖原视频。

若单一 ROI 无法同时保留标距细节与夹具上下文，应比较两种方案：

- **扩展 ROI**：保留试样和两端夹具，但去除大部分环境；
- **双视图输入**：原始全局视图加试样放大视图。只有在模型和训练格式明确支持时
  才采用双视图，不能在推理时临时添加。

### B.4 后续准备工作：数据与可追溯性

每条 ROI 派生产物必须记录：

- 来源原视频/子视频 ID；
- ROI 坐标、裁剪规则版本、输出分辨率；
- 原始帧到裁剪帧的映射、时间戳和实际输入帧列表；
- 审核状态，以及裁剪后是否仍可人工判断断裂类型和位置。

新 ROI 产物必须重新执行媒体存在性、时间区间、标签组合和 train/val/test 隔离检查。
不得因为裁剪而改变已有标签的语义；若裁剪使 location 无法判定，应进入人工复审，
而不是静默沿用原标签。

### B.5 验证与决策门槛

ROI 不能只凭“画面更大”被采用。它必须在同一模型、同一 split、同一 prompt 和
同一生成配置下，与原始视图比较，并同时检查：

- 人工是否更容易在实际输入帧中识别断裂和位置；
- 同源正负配对的翻转成功率是否提高；
- `has_fracture`、type/location、区间与 joint success 是否不降或提升；
- 位置、齐根断裂和未夹紧等依赖夹具上下文的样本是否被裁剪破坏。

若 ROI 使人类或模型失去位置判断所需的夹具/标距信息，应缩小裁剪强度、采用扩展
ROI，或终止该具体裁剪方案。

## 当前两条方向的协作与实施顺序

1. **审计现有输入帧**：先确认当前 8 帧输入中，断裂是否对人可见。
2. **建立同源配对基线**：在原始/现有子视频上验证基座和微调模型的内容敏感性。
3. **生成 ROI 候选版本**：不覆盖原始数据，完成人工可见性审查与 metadata 记录。
4. **原始视图 vs ROI 对照**：同一模型、同一 split、同一 prompt 和生成配置下比较。
5. **若 ROI 有效，再重新构建训练数据并训练 LoRA**：训练与推理的 system/user
   prompt、裁剪规则和帧采样契约必须一致。
6. **最终验收**：在冻结 prompt、权重和 ROI 版本后，对独立测试源视频报告格式、
   断裂、类型、位置、区间和 joint success 指标。

以下情况应停止继续优化 prompt，优先修复视觉输入：

- 输入帧审计显示断裂事件不在模型输入中；
- 真实视频和遮挡/无关画面得到几乎相同的输出；
- 同源断裂前后片段无法触发预测变化；
- ROI 裁剪后人类也无法判定原标签。

## 通用非目标

- 不以更长的 System Prompt 替代视频证据；
- 不以训练或验证 loss 作为视觉理解证明；
- 不在当前电脑启动 GPU 训练或长时间推理；
- 不在未通过输入审计和配对验证前，声称模型已经理解材料拉伸过程。
