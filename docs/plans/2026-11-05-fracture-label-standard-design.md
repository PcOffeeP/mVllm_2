# 断裂标签标准草案

**状态：候选标准，供用户确认；2026-11-05。** 本轮整理标签及可见判据，不改变代码、契约、数据、既有断裂帧标注或评测口径。v4.1 保持冻结；PB-019 所述 v4.2 恢复实施仍暂停。本文定稿也不自动构成恢复实施授权。

**何时作废：** 用户确认本文内容并正式合入唯一权威标注规范，或用户取消本方案时，本文作废；按项目规则将应保留的设计事实并入 `docs/design-facts.yaml`，或删除本文，不长期保留第二套有效规范。

## 1. 要标什么，以及本稿的效力

建议将标注分成以下几类：先判断当前片段的断裂状态，再分别记录断裂模式、断裂位置、异常和伴随现象。这样，一段视频可以同时表示“发生断裂”和“可见层间分离”，不必把它们塞进同一类别。

| 类别 | 全部取值 | 选择方式与效力 |
| --- | --- | --- |
| 片段断裂状态 | 未断裂、发生断裂、已断裂、无法判断 | 单选；四状态方向已获用户接受，操作定义见第 2 节 |
| 断裂模式 | 脆性、韧性、半脆半韧、无法确定 | 单选；类别已获接受，判读边界见第 3 节 |
| 断裂位置 | 标距内、标距外非根部、夹持根部、无法确定 | 单选；类别已获接受，位置边界见第 4 节 |
| 异常 | 未夹紧、视频异常、爆炸性断裂 | 前两项已获接受；爆炸性断裂归项目异常已确认，具体判据及并存规则仍待确认 |
| 伴随现象 | 轴向伸长、局部缩颈、可见开裂、纵向劈裂、可见层间分离、束状散开 | 固定名词多选已确认；这份默认词表及可见判据是本项目建议，待确认 |

用户澄清“连接位断裂”实际指“临界未断裂”，并同意将其移出核心断裂状态。本稿的“未断裂”可包含尚未分离但已有可见变化的片段；具体变化由伴随现象记录，不据此预测片段之后会不会断裂。

**这与冻结 v4.1 有意不同。** 现行契约仍含“临界未断裂”五值及事件方向语义（DF-001，active）；本文四状态是候选标准，不能直接替换现行输出。源级断裂帧锚点仍按 DF-013（active）及[标签锚点标注规范](../label-annotation-spec.md)执行：`断裂帧_前` 为最后一帧仍连通，`断裂帧_后` 为第一帧已分离、也是权威值，时刻由实测 fps 派生。本稿的“可见开裂”等现象不改变该锚点。

以下操作定义均服务于本项目的视频标注，不声称是外部科学标准规定的标签集。已确认的分类方向与尚待确认的细化规则分别注明。

## 2. 片段断裂状态：只回答当前片段里看到了什么

标注单位是**当前提供的片段**。不得用后续片段、完整视频的未来画面或已知最终结果，替当前片段补出证据。源视频有断裂，也不等于每个子片段都“发生断裂”。源表的“未标注／无法判读”是标注进度与可判性，不是这套片段状态（见第 7 节）。未夹紧另有模式、位置不标的特殊规则；其片段状态填法仍是第 5 节的待确认建议。

| 状态 | 可操作判据 | 边界与信息不足处理 |
| --- | --- | --- |
| 未断裂 | 有足够清晰、连续的画面支持试样仍连通，片段内未出现可见分离 | 可以同时有伸长、缩颈或局部开裂；这些现象不自动等于整体已断。仅因没拍到断裂，不能选本项 |
| 发生断裂 | 片段内能建立“仍连通 → 首次可见分离”的变化 | 分离仍按既定锚点判；只看到已有裂缝、断后形态或突跳，未必足以证明事件发生在片段内 |
| 已断裂 | 可靠画面从一开始就已分离，片段内没有断裂前仍连通的证据 | 不要求知道片段外哪一帧断裂；若开头被遮挡，后来才见分离且无法定位事件，选“无法判断” |
| 无法判断 | 证据不足以在以上三项中作出可靠选择 | 例如关键时段遮挡、模糊、缺帧或试样离开画面；不等于“未断裂”，也不等于“未标注” |

“未断裂”描述可见结果，不表示没有损伤；“发生断裂”描述片段内事件，不表示裂纹从此刻才在物理上萌生。以上两点避免将可见现象与不可见的材料内部过程混为一谈。

## 3. 断裂模式：保留脆韧类别，证据不足就不强分

这类标签试图描述断裂前的变形特征与破坏方式。脆韧性的科学区分涉及塑性变形等证据；视频里看到“拉长”不必然证明塑性，看到“一瞬间断开”也不足以证明脆性。普通视频不能默认看清单纤维破坏或微观断口。

以下为**建议判读边界，待确认，正向判据仍需试标验证**。只有普通视频、仅能看到伸长、缩颈或断裂速度而无法可靠区分塑性时，默认记录现象，模式选“无法确定”。正向分类须说明用了什么证据、支持哪一种特征；不能只写“证据充分”。

可能支持判断的证据包括：片段内同一段试样卸载前后的形状对照，显示卸载后仍保留的变形；与本次断裂事件对应并经过适用解释的力学曲线；或针对该试样、由专业人员作出的断口判读。这些都**不是自动充分条件**：残余变形需排除滑移、视角变化等解释，曲线需分清试样响应与设备柔度等影响，断口特征需适用于该材料体系。缺少对应证据、解释有冲突或材料体系不适用，就选“无法确定”。

默认仍只看当前片段。力学曲线、专业断口资料等只有在本次任务明确提供并允许使用时才可作为补充依据，且须与该试样和事件绑定、在备注中注明；本文不授权扩看后续片段或用未来画面回填当前状态。

| 模式 | 何时可考虑 | 不能据此单独判定 |
| --- | --- | --- |
| 脆性 | 有上述适用且绑定本次事件的证据，支持断前塑性变形很少；须注明所依据的形变、曲线或专业断口判断 | “断得快”、低帧率下看不见变形、断后反弹；未见变形不能直接证明没有塑性变形 |
| 韧性 | 有上述适用且绑定本次事件的证据，支持断前发生明显塑性变形；例如可解释的卸载后残余变形，并说明与本次断裂的关系 | 夹具移动、弹性伸长或单纯层间张开；仅有这些画面时不够 |
| 半脆半韧 | 同一断裂过程的脆性与韧性特征各有独立支持，能分别指出证据及对应部位或阶段 | “拿不准脆还是韧”、先拉长后突然断、同时有分层与散束；不能把混合类当未知类 |
| 无法确定 | 已见断裂但模式证据不足、冲突，或只有断后画面；也包括连断裂是否发生都无法确定的情况 | 它是完成判读后的不确定结论，不是漏填 |

**候选默认填法，待确认：** 已明确片段一直未断时，模式记“不适用”；除未夹紧等已确认特殊规则外，片段状态为“无法判断”、连断裂是否发生也不清楚时，模式与位置均记“无法确定”，备注“断裂是否发生未知”。后者不表示已见断裂，不能写成“不适用”。“不适用”是填写状态，不新增模式类别；它与“无法确定”的具体存储方式待确认。

## 4. 断裂位置：先有区域依据，再选位置

标距是试验中指定的测量长度范围，不能把“画面中间”直接当成“标距内”。位置判断需要已提供的标距定义、标记或其他可靠定位依据，并且当前片段能把断裂处与这些区域对应起来。

| 位置 | 可见定义 | 反例或边界 |
| --- | --- | --- |
| 标距内 | 可定位的断裂处位于已明确的标距范围内 | 仅知断在试样中部，但标距边界不明，不够 |
| 标距外非根部 | 可定位的断裂处在标距外，且不在试样离开夹持约束的根部区域 | “靠近夹具”不自动等于根部；边界看不清则不强分 |
| 夹持根部 | 可定位的断裂处位于试样从夹具夹持区伸出的根部，即夹持约束交界附近 | 不是所有标距外断裂，也不是所有画面边缘断裂 |
| 无法确定 | 已见断裂但位置依据不足；或断裂是否发生本身未知，按第 3 节候选默认填法处理 | 标距不明即选本项；不能根据经验猜测标距长度 |

已明确片段一直未断时，建议位置记“不适用”；断裂存在未知时按第 3 节记“无法确定”并注明原因，存储方式待确认。跨多个区域同时破坏、边界正好落在断裂区的取值规则仍待确认，不擅定主位置或优先级。

## 5. 异常：项目标签不等于试验物理有效性结论

异常用于记录本项目关注的情况。爆炸性断裂归异常已获用户确认，**不因此推出该试验在科学或工程上必然无效**，也不自动决定其他字段全部清空。

| 异常 | 可操作定义或建议判据 | 边界 |
| --- | --- | --- |
| 未夹紧 | 有明确证据显示夹持未形成有效约束，例如试样相对夹具明显滑移、脱出，且能与试样伸长或断后回弹区分 | 夹具运动、瞬间抖动或断后回弹本身不足。用户已确认此类不标断裂模式和位置 |
| 视频异常 | 录制或画面缺陷影响当前判读，例如关键过程缺失、严重模糊、遮挡、跳帧或试样出画 | 需说明影响哪个判断；局部遮挡不意味着所有现象都不可观察 |
| 爆炸性断裂 | **建议判据，待确认：** 可见断裂伴随明显多处碎裂、碎片向多方向飞散或大范围崩散 | 单次快速断开、两端回弹、少量散束不单独构成本项；不能仅凭断裂速度判定 |

对**未夹紧**，用户已确认断裂模式和位置不标，本稿用“不适用”表达，不是“无法确定”，具体字段承载形式待确认。**片段状态建议填“无法判断”，待用户确认**；该建议参考冻结 v4.1 的现行要求，不代表新标准已确认这一组合。其他仍可辨的现象不因此自动消失。

对**视频异常或爆炸性断裂与断裂并存**，建议按字段保留有可靠证据的结果：能确认片段内分离，就保留“发生断裂”；某字段受影响，则单独标不确定。此规则**待用户确认**，不能当作已批准的跨字段规则，也不能覆盖前段的未夹紧特殊处理。

异常是否多选、是否设质量门、爆炸性是否触发样本排除、各类异常下哪些字段不适用或清空，均待确认。异常记录也应区分“已检查，未见异常”“部分无法判断”“未标注”；这套填写状态及表示方式尚待确认，空白不能被自动解释成“无异常”。

## 6. 伴随现象：固定名词多选，并说明观察覆盖

用户已同意将伴随现象从自由文字改成固定名词多选。以下是**建议默认词表，待确认**；一个样本可以有多项。口语“紧缩”在这里统一用**缩颈**，即试样局部相对相邻部分变窄，不泛指任何收缩或运动。

| 名称 | 什么证据才标阳性 | 不应混入的情况 |
| --- | --- | --- |
| 轴向伸长 | 沿加载方向，试样自身可追踪特征之间的距离增大，且能排除明显视角或镜头变化 | 单看夹具间距增大；试样整体平移、夹持滑移。不由此直接断定塑性 |
| 局部缩颈 | 同一局部区域相对相邻部分明显变窄，并能与初始形状和视角变化区分 | 原有窄段、转动造成的投影变窄、遮挡或整体均匀变细 |
| 可见开裂 | 可辨认新出现或继续扩展的裂缝、开口 | 原有纹理、反光、阴影；单纯两段已分离不必再补推裂缝形成过程 |
| 纵向劈裂 | 沿试样长度方向可见开裂，并出现条状或束状部分分离 | 任意方向的一条表面线；只见断口处散束、未见纵向发展 |
| 可见层间分离 | 能辨认不同铺层之间张开或滑开 | 仅见材料散开但无法辨认铺层；不能把一切裂缝、纵向劈裂都叫分层 |
| 束状散开 | 宏观可辨的丝束或刷状部分散开 | 仅见模糊飞散或毛边；不自动认定单纤维断裂、纤维与基体脱粘或纤维拔出 |

表面白化受材料和成像条件影响，暂列可选候选，待样本讨论，不纳入默认词表。后续增删词项应基于真实可辨样本，不为覆盖想象中的所有机理而扩表。

“可见开裂”与“纵向劈裂”有一般项与细分项的重叠。**建议允许共选，但评测不重复累加同一事实；具体共选及计分规则待确认。** 同理，不能因为选了“束状散开”就自动补选“可见层间分离”。

只存一个现象列表还不够：空列表无法区分“没有”“没看清”和“还没标”。建议同时记录观察覆盖，以下均为待确认的填写规则，不是新增断裂状态：

| 判读情形 | 怎样记录 |
| --- | --- |
| 已观察到某些现象 | 勾选有证据的现象；其余未勾项不自动算阴性 |
| 明确无可见现象 | 已完成检查且画面足以覆盖拟判的现象，明确记“无可见现象” |
| 部分无法判断 | 保留已见项目，同时注明哪些现象或时段无法判断；未知可以与阳性共存 |
| 整体无法判断 | 无可靠现象证据，明确记无法判断，不能记“无” |
| 未标注 | 尚未完成检查，明确记未标注，不生成阳性或阴性结论 |

可选自由文字备注保留，用于说明“先伸长、后断裂、断后看见层间张开”等时间顺序和证据限制。先后关系不自动表示因果；有因果解释时须标明推测。备注不能代替应选的固定名词，也不要求把多个现象压成一个标签。

## 7. 源表标注状态与片段断裂状态分开

[标签锚点标注规范](../label-annotation-spec.md)中的源表状态是“已标注·有断裂、已标注·无断裂、未标注、无法判读”，它回答的是**整条源视频的锚点标注是否完成、是否可判**。本文第 2 节的四状态回答的是**当前片段的断裂情况**，两者不能相互替填。

例如，整条源视频已标注有断裂，其断裂前子片段仍可以是“未断裂”；“源表未标注”不应转成片段“未断裂”。源级“未标注”和“无法判读”不产候选的既定要求继续由原规范负责。本文不引入空值回退、不改源表迁移和帧锚点判据。

## 8. 示例：瞬间断开，之后看到疑似分层

按用户描述讨论，**本例不是已复核的视频结论**。若当前片段清楚显示试样由连通变为分离，随后可辨认铺层之间张开，则建议标注：

| 类别 | 本例取值与理由 |
| --- | --- |
| 片段断裂状态 | 发生断裂：片段内有连通到分离的证据 |
| 断裂模式 | 无法确定：瞬间断开和层间分离不足以区分脆性、韧性或混合模式 |
| 断裂位置 | 无法确定：本例未提供断裂处与标距、夹持根部的定位证据；补齐证据后再判断具体位置 |
| 异常 | 待判；不能由断得快推定爆炸性断裂，也不能据此认定夹紧正常或异常 |
| 伴随现象 | 可见层间分离；只在确实可辨铺层时选，若仅见散开则不强标分层 |
| 可选备注 | “断裂后可见层间张开；断前模式证据不足。”不由画面先后推断分层是断裂原因 |

## 9. 确认后才能落地的事项

当前需确认的是这套候选标准的细化，不是重新讨论已经确认的帧锚点：

1. 是否接受默认现象词表、各标签可见判据和观察覆盖的区分；是否允许一般开裂项与纵向劈裂共选，以及怎样避免重复计分。
2. 是否接受模式判断的保守边界；“不适用、无法确定、未标注”如何分别承载，不能合成同一个无说明的空值。
3. 是否接受爆炸性断裂的可见判据；异常是否多选、异常与断裂并存怎样填写，以及是否关联样本质量或排除规则。仅“爆炸性归项目异常”已确认，不包含“物理试验无效”的裁定。
4. 多处断裂、区域交界等情况下的位置取值规则；标距和夹持根部的可靠定位依据如何提供。

本轮只交付文档，不执行补标、数据重建、真实评测或 test 使用。契约、Prompt、字段存储、评测及 v4.2 实施另需范围明确的授权。

## 10. 依据与适用限制

仓库依据以本轮核对的 active 设计事实 DF-001、DF-013 为准；实施暂停与冻结边界见[未结事项登记册](../pending-blockers.md)的 PB-019，源级锚点及标注状态见[标签锚点标注规范](../label-annotation-spec.md)。这些引用只支持各自范围，不给本文未决细则追加效力。

外部资料只用于校准术语与推断边界，不规定本项目标签集或视频阈值：

- [NIST：载荷下的衍射应力测量](https://www.nist.gov/programs-projects/ncal-diffraction-stress-measurement-under-applied-load)讨论局部缩颈与变形局部化，支持将“缩颈”与一般伸长区分；本文的视觉判据是项目建议。
- [Bower《Applied Mechanics of Solids》断裂机制概述](https://solidmechanics.org/Text/Chapter9_1/Chapter9_1.htm)区分脆韧断裂中的塑性变形特征，并指出复合材料可能难以简单二分；它不支持单靠断裂速度分类。
- [NASA：单向复合材料层内与层间断裂韧性比较](https://ntrs.nasa.gov/citations/20120016494)分别研究层内与层间断裂，并使用断口分析支持观察；本文据此保持层间分离与一般开裂的概念边界，不把普通视频当作微观机理鉴定。

上述可见定义、固定词表和跨字段建议是本项目候选设计，尚未通过实际样本试标或一致性验证。它们不代表已按某一试验标准判定试验有效性，也不代表模式分类已经具备足够视频证据。
