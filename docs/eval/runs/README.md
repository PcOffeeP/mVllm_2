### 3.2 Run B 无画面文字先验红灯结论

- **盲答坍缩现象**：在完全剥离图像帧的 Run B（[`20261125-minicpm-v45-runb-noimage-dev-v1/`](20261125-minicpm-v45-runb-noimage-dev-v1/)）中，`MiniCPM-V-4.5` 对全部 **210/210** 条样本恒定输出 `断裂状态 = 已断裂` 与 `断裂现象.伸长 = 是`，对其余 9 个字段恒定输出 `无法判断`（210/210 = 100%）。
- **两项红灯警示**：
  1. **「伸长」字段出现盲答反超**：Run B 仅靠恒定猜 `"是"` 在 `断裂现象.伸长` 上取得 **72/210 (34.29%)**，反而高于带画面视觉推理的 `tf-dev-v1`（26.67%，`unc` 69.05%）与 `vllm-dev-v1`（29.05%，`unc` 60.48%）。
  2. **「断裂模式」正确预测全部落在 `无法判断` 真值上**：三组 Run 在 `断裂模式`（`n=86`）上均得到 **10/86 (11.63%)**，三组的 10 次正确预测均来自模型输出 `无法判断` 并命中真值里的 10 条 `无法判断`（`vllm-dev-v1` 与 `runb-noimage` 全量 210/210 输出 `无法判断`，`tf-dev-v1` 为 209/210 输出 `无法判断`、1/210 输出 `脆性断裂`；三组对 `脆性断裂` / `韧性断裂` / `半脆半韧断裂` 的召回全为 `0`）。
- **后续解读纪律**：评测 `Qwen3-VL-8B-Instruct`、`InternVL3-8B`、`InternVL3_5-8B` 时，必须同步对照 Run B 与模型 `无法判断` 率，禁止仅凭单字段准确率判断视觉增益。
