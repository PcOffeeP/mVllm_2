## 3. 旧规则在现存旧标签下是否一致

### 3.1 旧规则实际做了什么

旧 `type` 是混合分类，既包含脆性／韧性，也包含未断裂、未夹紧、视频异常、界面脱粘、齐根断裂等。它不是当前单独的“断裂模式”字段。

旧代码先把 `type` 总数不超过 2 的视频放入稀有池，稀有池不进入 test 或 val，加入每一折 train。其余视频按旧 `type` 与 `location_canonical` 分层：位置为空时归入 `N/A`；样本数不超过 2 的类型位置组合尝试按位置合并为 `rare_fracture`；合并后仍有小层时退化为 `type_only`。测试集剥离后，对普通开发池重新计算分层。

每层测试配额为：层大小至少 2 时先取 `max(1, round(层大小 × 0.2))`，随后递减以尽力留下至少 3 个普通开发样本。普通开发池各层打乱后按 `ceil(层大小 / 3)` 连续切成三块，分别作为各折验证集，其余普通开发样本加稀有池作为训练集。因此三折大小不必相等，第三折可明显较小；稀有池不会轮到验证。

### 3.2 旧稀有池：六个始终训练 ID 可以解释

旧元数据中 `type` 的整体计数为：韧性断裂 51、脆性断裂 20、未断裂 15、界面脱粘 8、齐根断裂 6、视频异常 4、界面脱粘与齐根断裂组合 2、爆炸性断裂 2、未夹紧 1、半脆半韧断裂 1。

| video_0002 | 未夹紧 | 无 | 每折 train，未进入 val 或 test |
| video_0014 | 半脆半韧断裂 | 半脆半韧断裂 | 每折 train，未进入 val 或 test |
| video_0017 | 界面脱粘、齐根断裂 | 半脆半韧断裂 | 每折 train，未进入 val 或 test |

### 3.4 历史来源仍有缺口，不能声称精确重演

上述结论仅表示**现存旧元数据与固定划分在可检查规则上相容**。旧元数据与 JSON 都是本机被忽略文件，尚无经核实的同一运行绑定、输入快照 manifest 或生成日志把二者与提交关联起来。文件里 `seed: 42` 是元数据声明，本次没有验证其历史随机序列与逐 ID 抽样重演。

还存在可以直接观察到的格式差异：现存折文件的 `split` 是 `train` 或 `val`、`test_ratio` 是 `null`；当前提交的 `_split_payload` 把完整名称（如 `fold_0_train`）写入 `split`，并统一写 `test_ratio: 0.2`。不能把当前代码的输出格式与现存文件说成完全一致。此差异不否定配额核查，但阻止将其升级为“该提交精确生成了这些文件”的结论。

### 4.2 现有归属下的覆盖缺口

| 观察 | 对评价证据的影响 |
| --- | --- |
| test 和三个 val 的 `异常_未夹紧`、`异常_爆炸性断裂` 均无“是”正例 | 这些源级分区不能提供对应正例的识别证据；正常／负例的数量不能代替正例。 |
| test 的 `现象_开裂` 无“是”正例 | test 源级标签无法检验开裂正例识别。 |
| fold 2 val 的 `现象_开裂`、`现象_断后脱夹` 无“是”正例 | 该折相应源级正例表现不可估计。 |
| fold 1 val 无 `未断裂` | 该折源级状态标签不覆盖未断裂；不能据此推断实际子片段必然没有该状态。 |
| 全体 `异常_未夹紧` 仅 1、“爆炸性断裂”仅 2、“开裂”仅 3 个正例 | 重分配只能移动独立来源，不能凭空增加独立正例；是否允许缺项及如何报告须事先确认。 |

以上说明当前清单对新任务存在覆盖限制；不等于已违反某条正式的新分层标准。即使调整划分，样本量不足、未知值处理和片段自身可见性仍要分别解决。

### 4.3 仅按新模式的代理压力测试：不作正式合规判定

为直观看出新旧定义的结构性差异，本节作一个**未确认的代理假设**：临时将新“断裂模式”当作旧 `type`，完全忽略位置，并沿用旧 20% 测试配额与三折向上取整切块。这不是已确认映射，也不是完整旧分层算法在新数据上的结果；本次未生成任何候选划分。

在此假设下，新模式五个原值的数量均大于 2，稀有池应为空；现有清单却仍有上文六个旧稀有 ID 始终训练。表中代理验证块按“该模式总数减去代理测试配额”计算，不能与含旧稀有池且 test 配额不同的实际开发集当成同一输入。例如脆性断裂实际开发数为 21−3=18，代理开发数为 21−4=17，因此代理块为 [6,6,5]，并非对实际 18 条重新分配。

| 新模式原值 | 总数 | 实际 test | 代理 test 配额 | 实际 val（0、1、2） | 代理 ceil 块（0、1、2） |
| --- | ---: | ---: | ---: | --- | --- |
| 半脆半韧断裂 | 20 | 4 | 4 | [6,4,3] | [6,6,4] |
| 无 | 4 | 1 | 1 | [1,0,1] | [1,1,1] |
| 无法确定 | 15 | 3 | 3 | [4,3,5] | [4,4,4] |
| 脆性断裂 | 21 | 3 | 4 | [4,7,5] | [6,6,5] |
| 韧性断裂 | 50 | 10 | 10 | [15,16,9] | [14,14,12] |

实际验证合计少于“总数减实际 test”的模式：半脆半韧少 3、无少 1、脆性少 2，恰为六个旧稀有 ID 的新模式归属。这说明旧稀有池规则和新模式覆盖目标之间需要重新讨论。它不足以证明旧规则被违反，更不足以单独决定重新划分。
