## 步骤目标与范围

本步骤把现有 110 个原始视频和 CSV 标注转化为可复现、无原视频级泄漏、能够被 LLaMA-Factory 实际加载的 MiniCPM-V 4.6 微调数据。完成后应具备三折训练与验证数据、严格隔离的最终测试输入清单、完整数据统计和可执行的质量校验。

本步骤只建设数据基础，不执行正式模型训练，不修改 Agent 的迭代策略，也不生成最终竞赛评估结果。模型输出和标签口径必须先符合项目计划中的统一规则；若仓库中的 Prompt、Schema 或校验逻辑仍接受边界哨兵或 `N/A`，应先完成项目计划第 1 步，再运行本数据流程。

## 实施方案

以 `data/02_annotations/all_videos_tag.csv` 为原始标签依据，保留所有原字段，并通过 canonical 字段表达训练口径。视频级库存分为四组：88 个确认断裂视频、7 个确认未断裂视频、1 个未夹紧视频和 14 个无法确认断裂行为的视频异常样本。视频异常是独立的“不确定/异常”类别，不计入干净负样本平衡，也不能在 Agent 中作为确认未断裂证据；它仍以完整视频形式参与训练和库存统计。

正样本的 `fracture_between` 只允许 `[i, i+1]`。第 `i` 张采样帧必须尚未断裂，第 `i+1` 张采样帧必须已经断裂，CSV 的 `event_frame_original` 视为第一张明确出现断裂的原始帧，因此合法标签满足 `sampled_frame[i] < event_frame_original <= sampled_frame[i+1]`。不再生成或接受 `[0,0]`、`[N-1,N-1]`。无法被两张实际采样帧包围的片段先调整时间范围重新生成；仍不合法时排除该片段并记录原因。

确认断裂样本的位置只使用 `inside_gauge` 或 `outside_gauge`。确认未断裂、未夹紧和视频异常样本的位置为 `null`。不人为制造 `unknown` 训练标签；`unknown` 由 Agent 在多轮位置结果冲突或证据不足时产生。人工构造的断裂前后负片段使用 `type=未断裂`，父视频真实模式和位置仅保存在追溯 metadata 中。训练回答中的 `confidence=1.0` 只表示监督标签确定，不视为经过校准的推理置信度。

划分以原视频为最小单位并使用固定随机种子。原视频数不超过 2 条的三个稀有断裂类别共 5 个视频组成训练专用池，加入每个 fold 的训练集，不进入验证集或测试集。其余视频先划出约 20% 作为冻结测试集，剩余视频进行三折划分。任何由同一原视频产生的片段只能跟随原视频进入同一个集合；测试视频不得出现在任一训练或验证产物中。

训练正样本保留完整视频引用，以及围绕断裂点构造的 3 秒、10 秒和 30 秒片段，并覆盖断裂出现在片段 20%、35%、50%、65% 和 80% 位置的情况。完整视频直接引用 `data/01_videos`，不复制到子视频目录。实际生成的媒体只包含必要的聚焦片段和负片段。

训练负样本主要来自两类可靠来源：确认断裂视频中与断裂点保持安全间隔的断裂前后片段，以及确认未断裂视频中的固定长度、固定位置片段。未夹紧视频保留完整视频，并可生成少量高重叠、覆盖主要拉伸过程的长片段；视频异常只保留完整视频。先建立候选样本清单，再按固定种子、每个原视频上限和类别上限选择实际样本，使每个 fold 训练集的确认断裂正样本与干净负样本比例处于 `1:1` 至 `2:1`。验证集不通过复制或重采样改变分布，视频异常数量单独报告。

不为所有样本永久保存帧图。数据生成器记录理论采样帧的原视频索引和时间戳，只为覆盖全时长、3 秒、10 秒、30 秒、正样本、负样本及边界位置的审计样本保存帧图。正式全量生成前，必须用这些小样本通过 LLaMA-Factory/MiniCPM-V 的真实视频预处理链路核对实际帧数量、顺序和时间映射；理论与实际不一致时停止全量生成并修正规则。

训练和验证产物使用带 `system`、`user`、`assistant` 的 ShareGPT 多模态格式。最终测试输入与真值严格隔离：模型和 Agent 使用的测试清单只包含视频 ID 和视频路径，不包含断裂时刻、模式、位置、assistant 答案或任何由真值生成的切片；预测完成后，独立评估程序才读取 CSV 真值评分。测试期间的所有切片均由 Agent 或与真值无关的固定规则产生。

## 执行清单

- [ ] 核对统一接口前置条件，确认 Prompt、Schema、样本构造和校验器均只接受严格相邻帧，并对负样本使用 `location=null`；形成一致的可执行标签规则。
- [ ] 建立 110 个原视频的权威库存，输出原始标签、canonical 标签、四类语义分组、视频存在性、帧率、总帧数、时长、断裂帧边界检查和治理原因统计。
- [ ] 实现训练专用稀有类别池和确定性视频级划分，冻结测试 ID，验证每个 fold 的训练/验证互斥关系及测试集与全部训练产物的隔离关系。
- [ ] 建立正样本、干净负样本、未夹紧和视频异常的候选样本清单，按来源上限和固定种子完成训练集平衡选择，并输出每个 split 的视频级与样本级分布。
- [ ] 调整媒体生成路线，使全时长样本引用原视频，只为选中的聚焦和负样本生成子视频，并仅为审计样本保留帧图；记录缺失、裁剪失败和排除原因。
- [ ] 用覆盖不同长度、类别和断裂位置的小样本运行真实视频预处理核对，确认理论采样帧与 MiniCPM-V 实际输入帧一致，且所有正样本满足“前帧未断、后帧已断”的标签规则。
- [ ] 小样本核对通过后生成全量训练与验证子视频、元数据和 ShareGPT JSON；生成不含真值字段的最终测试输入清单，并保持评分真值只对评估程序可见。
- [ ] 运行全量质量校验，检查媒体路径、JSON 格式、标签闭集、严格相邻帧、正负比例、来源上限、原视频级泄漏、测试真值隔离和生成失败记录；缺少预期产物时校验必须失败而不是跳过。
- [ ] 使用三个 fold 的训练和验证数据分别完成 LLaMA-Factory 数据加载冒烟检查，确认视频可解码、Prompt 与媒体数量一致、样本能够进入一个实际 batch，随后冻结数据清单与生成参数。

## 预期结果

完成后，仓库本地应存在可复现的视频元数据、三折视频级划分、冻结测试输入清单、必要子视频、子视频追溯 metadata、三个 fold 的训练与验证 ShareGPT JSON，以及汇总各类别、各来源、正负比例、排除样本和磁盘占用的数据报告。所有生成产物继续遵循仓库忽略规则，不提交原始视频、子视频、帧缓存或大型训练 JSON。

数据集能够直接被现有 interval 训练配置引用；正式测试只接收无真值的视频输入，评分程序在推理结束后独立读取 CSV。实施完成并不代表模型效果已达到竞赛目标，只代表训练与公正评估所需的数据基础已经可靠建立。

## 验收标准

- 原始库存恰好覆盖 CSV 中的 110 个视频 ID，视频文件无缺失、无额外 ID、无空文件；95 条带断裂帧的原始记录均完成边界检查，7 条冲突记录保留原字段并产生明确治理记录。
- canonical 库存能够复现 88 个确认断裂、7 个确认未断裂、1 个未夹紧和 14 个视频异常；64 个标距内和 24 个标距外的有效断裂位置均未被改写。
- 三个稀有断裂类别共 5 个视频只出现在每个 fold 的训练集；冻结测试集不含这些视频，且不与任何训练或验证来源视频相交。
- 每个普通非测试视频在三折验证集中恰好出现一次；同一 fold 的训练集与验证集不共享原视频，任何子视频均可追溯到唯一的 `source_video`。
- 所有正样本均满足 `sampled_frame[i] < event_frame_original <= sampled_frame[i+1]`，`fracture_between` 严格为 `[i,i+1]` 且索引未越界；全量产物中不存在边界哨兵。
- 训练集中确认断裂正样本与干净负样本比例位于 `1:1` 至 `2:1`，视频异常和未夹紧单独统计；验证集和测试集没有为满足比例而复制样本。
- 确认断裂样本的位置只包含 `inside_gauge` 或 `outside_gauge`，其他类别的位置为 `null`；训练数据中不存在人为生成的 `unknown`。
- 全时长样本全部引用原视频，没有重复复制 6.2GB 原始视频；永久帧缓存仅覆盖审计样本，数据报告给出实际子视频和帧缓存占用。
- 真实预处理核对覆盖全时长、3 秒、10 秒和 30 秒片段，理论与实际输入帧数量、顺序及映射完全一致；不一致时全量数据不得被标记为可训练。
- 训练和验证 JSON 能被 LLaMA-Factory 成功解析并各加载至少一个实际 batch，所有引用媒体均存在且可解码，Prompt 中的视频数量与媒体字段一致。
- 测试输入清单不包含事件帧、断裂时间、模式、位置、assistant 答案或真值派生切片；模型与 Agent 推理流程不读取 CSV，评分程序只在预测完成后访问真值。
- 全量校验在产物完整且合法时返回成功；任一预期文件缺失、数据泄漏、非法标签、路径失效或非相邻帧存在时返回失败。

## 风险与待确认事项

- [非阻塞] 即使不复制完整视频，3 秒、10 秒、30 秒聚焦片段和负片段仍可能占用较大空间；先根据候选清单估算空间，再只生成最终选中的媒体。
- [非阻塞] `视频异常`表示无法判断是否断裂，而当前微调协议仍以异常类别表达该语义；数据统计和后续 Agent 逻辑必须避免把它当作确认未断裂证据。
- [非阻塞] `未夹紧`只有一个原视频，增强片段不能替代真实来源多样性；报告中需明确其来源数，不能仅用片段数量夸大覆盖度。
- [非阻塞] 所有训练回答使用 `confidence=1.0`，该字段不能据此视为已校准；置信度校准属于后续模型验证与 Agent 聚合范围。
- [非阻塞] LLaMA-Factory 与本地元数据计算的抽帧细节可能因版本或编码变化产生偏差；真实预处理核对是全量生成前的强制门槛。
