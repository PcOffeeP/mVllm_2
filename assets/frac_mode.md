# 材料拉伸断裂行为分类指南

> 定位：用于理解视觉现象的领域参考，不是训练标签或代码枚举的权威来源。
> 标签治理以 [`data/02_annotations/all_videos_tag.csv`](../data/02_annotations/all_videos_tag.csv) 为准，
> 代码闭集以 [`agent/schema.py`](../agent/schema.py) 及相关验证配置为准；本文不得覆盖 CSV 原字段或 canonical 口径。

## 一、按材料类型分类

### 1. 金属材料

#### 1.1 韧性断裂（ductile fracture）
- **断裂特征**：试样随载荷增加逐渐变长、横截面轻微变细，试样的横截面突然快速变细，形成"颈缩区"，**颈缩区**最终被"拉断"
- **断裂过程**：缓慢，有**颈缩**

#### 1.2 脆性断裂（brittle fracture）
- **断裂特征**：从加载开始到断裂前，试样几乎无肉眼可见的伸长或横截面变细，断口平齐基本无凹凸
- **断裂过程**：瞬时发生

---

### 2. 高分子材料

#### 2.1 脆性断裂（brittle fracture）
- **断裂特征**：断裂前无明显塑性变形，试样长度、横截面尺寸无任何变化
- **断裂过程**：瞬时发生

#### 2.2 韧性断裂（ductile fracture）
- **断裂特征**：拉伸初期试样先"均匀伸长"（长度增加、横截面轻微变细），断裂无脆响
- **断裂过程**：相对缓慢，有**伸长**
---

### 3. 无机非金属材料

#### 3.1 半脆半韧断裂（brittle-ductile fracture）
- **断裂特征**：拉伸时试样有少量整体伸长（伸长率5%～20%），断裂前变形程度中等，既无脆性断裂的"瞬时性"，也无韧性断裂的"充分伸长"，试样有轻微残余变形，但整体形态仍较规整，断口部分平整

#### 3.2 脆性断裂（brittle fracture）
- **断裂特征**：从加载开始到断裂前，断裂后试样两段保持原始形态，无变形
- **断裂过程**："突然发生"

---

### 4. 复合材料

#### 4.1 脆性断裂（brittle fracture）

- **断口特征**：断口平整，断裂突然发生

#### 4.2  韧性断裂（ductile fracture）

- **断裂特征**：试样出现伸长/塑性变形，断口平坦

---

## 二、其他特殊情况

### 5. 异常断裂模式

| 断裂类型 | 主要特征 |
|---------|---------|
| **爆炸性断裂（explosive fracture）** | 断裂时伴随碎片飞溅 |
| **齐根断裂（grip-end fracture）** | 断口紧靠夹具夹持端 |
| **未断裂（no fracture）** | 试样完整连续，无断裂分离 |
| **夹具打滑/未夹紧（friction slip/unclamped）** | 夹具未夹紧试样，在拉伸过程或拉伸后出现试样偏移与脱离 |
| **加强片脱落（stronger plate drop）** | 加强片在拉伸过程中脱落 |
| **视频异常（video anomaly）** | 未记录下来完整的断裂过程 （但视频中存在断裂现象）|
|**界面脱粘（interface tear-off）**|纤维与基体间存在明显间隙，局部出现"微鼓包"或“层间分离”|
