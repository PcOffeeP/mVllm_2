# 文档路径自检白名单（scripts/verify_design_facts.py --check-doc-paths）
#
# 语义：脚本对每条规则用 re.fullmatch 逐条匹配（不做子串搜索，因此规则必须写全整条路径）。
#   refs: <regex>              匹配「引用路径本身」，豁免该路径的所有出现处；
#   files: <regex>             匹配「引用所在文件」（相对仓库根），豁免这些文件里的所有引用；
#   refs: <regex> files: <rx>  同行给出两个正则（顺序不限），两者都匹配才豁免。
# 豁免按出现处判定：同一路径在历史文档里被豁免，不会连带豁免其他文件里的同名引用，
# 因此当前权威文档里的引用必须单独登记（见下方「现行文档逐条收口」段）。
# `#` 开头为注释，空行忽略；0 命中的规则会打印 UNUSED RULE（防止只增不减）。
